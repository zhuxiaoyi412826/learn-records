# 技术方案简介：Node.js + tRPC + Vite + Tauri 个人全栈多端快速开发方案

本方案面向个人开发者，采用**Monorepo 单仓库架构**，实现一套代码完成前后端业务开发，同时支持 Web 网页、Windows/macOS/Linux 桌面客户端、Android/iOS 移动端多端构建输出，兼顾开发效率、类型安全与多端交付能力，适合个人 SaaS 工具、管理后台、联网型桌面应用等场景。

## 技术栈组成

- **后端服务**：Node.js（Bun）+ TypeScript + tRPC + Prisma ORM 基于 tRPC 构建类型安全的 API 服务，摒弃传统 REST 接口的重复类型维护，实现端到端 TS 类型校验，负责云端业务逻辑、数据库交互、鉴权校验，提供 HTTP 接口供前端调用。
- **前端客户端**：Vite + TypeScript + Tauri 2.x Vite 提供极速开发热更新能力，构建统一的 UI 业务代码；Tauri 作为跨端打包框架，将 Web 前端编译为多端产物；Tauri 内置 Rust 原生层，提供本地文件读写、本地数据库、系统托盘等客户端原生能力，与云端 tRPC 服务相互独立。

## 整体架构

项目采用 pnpm monorepo 管理，拆分后端服务包与前端客户端包。

1. **云端服务层**：独立 Node.js tRPC 服务，对外暴露 HTTP 接口，处理云端业务、持久化数据；后端定义 tRPC 路由，导出`AppRouter`类型，供前端仅导入类型，不引入运行时代码。

2. 客户端层

   ：Vite+TS 编写统一业务 UI，可编译输出 Web 网页；通过 Tauri 打包为桌面端、移动端应用。

   - 联网业务逻辑：前端通过 HTTP 请求调用 Node‑tRPC 云端接口，享受完整的 TS 类型提示、编译期校验，无需手写接口文档。
   - 本地系统能力：前端通过 Tauri IPC 调用 Rust 原生命令，实现文件操作、本地存储等客户端能力，与云端 API 互不干扰。
