# 功能详情

## 一、用户体系（核心）

1. **注册**：手机号 / 账号密码注册、验证码（短信 / 图形验证码）、密码加密存储（Argon2/BCrypt）
2. **登录**：账号密码登录、token 登录（JWT）、自动登录、单点登录
3. **用户信息**：头像、昵称、个性签名、在线状态（在线 / 离线 / 忙碌）
4. 好友模块
   - 添加好友（申请、同意、拒绝）
   - 好友列表、删除好友、拉黑好友（拉黑后无法收发消息）
   - 好友备注
5. 会话列表：最近聊天会话（单聊 / 群聊），按最后消息时间排序，未读消息计数

## 二、单聊（一对一聊天）核心功能

1. 实时收发文本消息
2. 消息状态：**发送中、已发送、已送达、已读**（核心交互）
3. 消息撤回（限时撤回，比如 2 分钟内）
4. 消息删除：本地删除 / 双向删除
5. 离线消息：用户离线时收到消息，上线后推送
6. 消息支持：表情、图片、文件、语音

## 三、群聊（多人聊天室）

1. 创建群聊、修改群名称、群公告、群头像
2. 邀请好友入群、扫码入群、踢出成员、退群、解散群
3. 群成员权限：群主、管理员、普通成员
4. 群消息：@某人、全体 @、群消息已读回执（可选，开销大）
5. 群禁言：全员禁言、单独成员禁言

## 四、消息基础能力

1. 消息类型
   - 文本消息
   - 图片（上传到对象存储 MinIO）
   - 文件（文档、压缩包）
   - 语音消息（可选）
   - 系统通知消息（入群、加好友、撤回消息等）
2. **消息持久化**：消息入库，历史消息滚动加载（分页拉取）
3. 消息排序、消息 ID 全局唯一、**消息幂等（防止重复发送）**
4. 消息检索：按关键词搜索历史聊天记录（可选，可对接 ES）

## 五、实时推送（通信层）

1. WebSocket 长连接建立、断线重连（网络波动自动重连）
2. 心跳检测：客户端定时 ping，服务端 pong，检测连接断开
3. 连接多端登录：
   - 单设备登录：异地登录踢下线
   - 多端同时在线（手机 + 网页），消息多端同步
4. 消息分发：路由消息到目标在线用户

## 六、高级扩展功能（可选，按需取舍）

1. 消息转发
2. 聊天引用回复（回复某一条历史消息）
3. 阅后即焚（限时自动删除消息）
4. 好友动态 / 朋友圈（可选）
5. 视频通话 / 语音通话（需要 WebRTC，成本高）
6. 敏感词过滤：消息发送前拦截违规内容
7. 消息加密：端到端加密（高安全需求才做）
8. RAG智能客服机器人

## 七、后台管理功能（运营端）

1. 用户管理：查看用户、冻结账号
2. 消息审计：聊天记录查询、敏感内容检索
3. 群管理：查看所有群组、强制解散、踢人
4. 黑名单管理
5. 数据统计：在线人数、消息量、新增用户

## 八、运维 & 监控（你当前重点，配套 logback 日志）

1. 链路追踪：每条消息生成 traceId，MDC 埋点
2. 日志埋点规范（沿用你之前的 5 问原则）
   - WebSocket 连接建立 / 断开日志
   - 消息接收入口、消息分发、消息入库、推送失败（ERROR）
   - 慢查询：历史消息分页查询（慢 SQL 单独落 BF-slow 日志）
   - 安全审计：异常登录、频繁发消息、拉黑操作、敏感词拦截（WARN）
3. 监控指标：在线用户数、消息 QPS、推送失败率、连接数
4. 限流：防止恶意刷屏，单位时间限制消息发送次数
5. 异常告警：服务断开、消息堆积、数据库异常
6. EFK



## **模块划分**

| 模块名称                       | 职责                                                         | 对应需求功能                               |
| ------------------------------ | ------------------------------------------------------------ | ------------------------------------------ |
| **user 模块 用户中心**         | 用户注册、登录、JWT 鉴权、用户资料、在线状态管理             | 注册、登录、头像昵称、在线状态             |
| **friend 模块 好友关系**       | 好友申请、同意 / 拒绝、好友列表、删除好友、拉黑、好友备注    | 好友全部功能                               |
| **conversation 模块 会话管理** | 会话列表维护、会话基础信息、未读消息计数                     | 单聊 / 群聊会话、未读数、会话排序          |
| **im-message 模块 消息核心**   | 消息收发、消息状态（发送 / 送达 / 已读）、撤回、删除、离线消息、消息幂等、消息持久化、历史消息分页查询、消息类型处理（文本 / 图片 / 文件 / 系统通知） | 单聊消息、消息存储、消息检索、系统通知消息 |
| **group 模块 群组管理**        | 创建群、修改群信息、成员管理、权限（群主 / 管理员）、禁言、@提醒、解散群 | 群聊全部功能                               |

| **websocket 模块 实时推送**    | WebSocket 连接管理、心跳、断线重连、消息路由分发、多端登录踢下线 | 长连接、消息实时推送                       |
| **common 公共模块**            | 全局异常、统一返回、工具类、Lombok DTO、Knife4j 文档、日志 AOP、MDC、加密工具 (Argon2/BCrypt)、JWT 工具、常量、过滤器 | 所有模块共享能力                           |

## 页面跳转链路（用户正常使用流程）

1. 未登录 → 登录 / 注册页
2. 登录成功 → 【会话列表首页】
   - 点会话 → 聊天窗口（单聊 / 群聊）
   - 切换标签 → 好友列表
     - 添加好友 → 好友申请页
     - 点击好友 → 用户资料页
3. 个人头像 → 个人中心、设置

## 页面简化方案（如果想进一步减少页面数量）

- 把「好友申请页面」**内嵌到好友列表页面**，做成 Tab，不用独立路由页面
- 个人资料页面做成弹窗，不新开路由页面
- 群详情页可以做成侧边抽屉，不单独新开页面

## 前后端对接要点

1. WebSocket 长连接在**聊天窗口**建立；页面关闭 / 切页面时断开或保活心跳
2. 未读红点由后端会话接口返回未读计数，前端渲染红点
3. 消息状态（已读）：前端打开会话窗口，自动调用接口标记消息为已读
4. 文件上传：聊天页上传图片，先调用 file 模块上传，拿到 url，再发送消息
