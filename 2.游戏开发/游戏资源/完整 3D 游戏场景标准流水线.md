先明确核心原则： **先布局白盒 → 单体资产制作 → 资产摆放 → 光照烘焙 → 后期特效** 所有模型资产（树木、建筑、道具）遵循角色同款规则：拓扑 → UV → 纹理，**资产定型之后再进场景组装**。

## 一、整套场景总流程（实时游戏标准流水线）

```
1. 场景策划/概念图 → 2. 白盒布局（Blockout）
→ 3. 单体3D资产制作（建筑、地面、植被、道具）
→ 4. 场景组装、摆放、碰撞设置
→ 5. 环境搭建（天空、雾、大气）
→ 6. 光照设置 + 光照烘焙
→ 7. 植被散布、LOD优化、实例化
→ 8. 特效、粒子、音频挂载
→ 9. 测试性能、剔除冗余资源
→ 10. 打包导出/导入游戏引擎
```

## 分步详细拆解，结合你熟悉的名词（UV、纹理、模型）

### 1. 概念与白盒阶段（Blockout 布局）

不用精致模型！只用简单立方体、平面搭建空间。 目标：确定地图大小、房间位置、道路、掩体、高低地形、玩家行进路线。 ✅作用：提前验证玩法，避免精细模型做完发现空间布局不合理，大规模返工。 工具：Blender / Godot / Unity 直接搭建基础几何体。

### 2. 单体资产制作（场景里每一个物件：墙体、箱子、楼房、石头）

> **单个静态道具标准流程（无骨骼，区别于人物角色）** 高模雕刻 / AI 生成模型 → **重拓扑（低模） → UV 展开 → PBR 纹理贴图**

1. 重拓扑：产出面数可控的低模（游戏实时渲染使用）
2. UV：拆分 UV，区分两种用法
   - 独立 UV：小型道具（箱子、油桶），单独贴图
   - 图集 UV / 平铺 UV：地面、墙面、路面，使用重复贴图（Tile）
3. 纹理：Albedo 固有色、法线、粗糙度、AO 贴图

> 👉动态场景物件（门、可移动箱子）： 资产流程同上，额外增加：**骨骼 / 简单绑定、动画**（开门动画、升降动画）

⚠️关键区别：**场景静态道具 95% 不需要骨骼、不需要蒙皮！只有会动的物体才做骨骼。**

### 3. 场景组装（场景搭建）

把做好的所有 FBX 资产导入引擎，按照白盒布局摆放。

- 对齐地形、搭建建筑群
- 摆放杂物：掩体、垃圾桶、装备箱
- 设置**碰撞体**：墙体、地面添加碰撞，玩家不能穿模
- 分层管理：建筑层、植被层、道具层、交互物体层

### 4. 地形制作（大型室外场景）

两种方案：

1. 引擎内置地形工具（Godot/Unity 地形笔刷）：拉高山脉、凹陷河道，绘制草地泥土路面
2. Blender 制作高度图 → 导入引擎生成地形，再混合多层纹理

### 5. 环境基础设置

天空盒 / 程序化天空、雾效、风向、环境光颜色，奠定场景整体色调。

### 6. 光照工作流（实时场景最重要环节）

1. 放置光源：太阳光、室内点光源、射灯
2. 区分：动态光 / 静态光
3. **光照烘焙（Lightmap）** 把静态物体阴影预先烘焙成贴图，大幅提升帧率。

> 烘焙依赖【第二套 UV（Lightmap UV）】 也就是模型除了基础 UV（贴纹理），额外一套 UV 专门用来存储光影，不会和材质贴图冲突。

### 7. 性能优化（游戏必备）

1. **LOD 层次细节**：远处模型自动切换低面版本
2. 植被实例化：成千上万树木、草丛不能单独摆放，开启实例渲染
3. 遮挡剔除：被墙体挡住的物体，引擎直接停止渲染
4. 合并静态网格：大量小道具合并，减少渲染批次

### 8. 交互、特效、后期

- 粒子特效：火焰、烟雾、水流
- 后期处理：景深、色调、抗锯齿、泛光
- 交互逻辑：触发区域、可拾取物品、门开关触发动画

## 二、【角色流水线 VS 场景道具流水线】对比，方便你区分

### 人形角色（士兵）

模型拓扑 → UV → 纹理 → **骨骼搭建 → 蒙皮绑定 → K 动画**

### 场景静态道具（箱子、墙体、石头）

模型拓扑 → UV → 纹理 ✅到此结束，不需要骨骼、不需要蒙皮

### 场景动态物件（门、升降平台）

模型拓扑 → UV → 纹理 → **简单骨骼 / 关键帧动画（少量骨骼，无需复杂蒙皮）**

## 三、两种常见场景管线区分

### A）实时游戏管线（你正在做的，Godot/Unity）

追求帧率，大量使用低模、烘焙光照、LOD 优化，上面整套流程。

### B）影视离线渲染管线（动画短片）

不限制算力，可以使用高模直接渲染，不需要严格减面，依靠光线追踪，一般不做光照烘焙。

## 四、新手高频错误顺序（避坑）

❌错误：先摆放一堆精致模型，之后修改地图布局 → 大量模型挪位置、报废 ✅正确：**先白盒布局确认地图，再制作精细资产**

❌错误：资产做好，UV 乱做、不做第二套光照 UV → 烘焙阴影出现大量黑线、扭曲 ✅正确：道具拓扑完成，同时做好材质 UV + Lightmap 光照 UV

❌错误：场景摆满模型之后再优化面数 → 工作量巨大 ✅正确：制作资产阶段就控制面数，源头优化
