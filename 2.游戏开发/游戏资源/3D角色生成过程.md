# 标准游戏 3D 角色完整流水线（写实战术士兵，适配 Blender→Unity/Godot）

> 分【两种主流工作流】，重点区分：**AI 生成模型流水线**（你现在的场景）、**从零手工建模流水线** 先记住黄金原则：**拓扑 → UV → 贴图 → 绑骨蒙皮 → 动画** ❌严禁顺序颠倒！顺序错会出现大量无法修复的 bug。

## 方案 A：从零手工制作角色（雕刻路线，专业标准流程）

适合：Blender/ZBrush 手工雕刻角色

1. **基础模型 / 高模雕刻** 在 ZBrush/Blender 雕刻出高精度高模，做出衣服褶皱、装备细节

2. **重拓扑（Retopology）** 在高模表面搭建布线干净、面数合适的**低模**（游戏最终使用模型）

3. 展开 UV（UV Unwrap）【重点！先 UV，后绑定！】

   ✅低模拓扑完成后立刻展 UV 把 3D 模型外皮摊成 2D 平面，用来绘制纹理贴图

   > 为什么不能绑骨后展 UV：绑定后修改模型拓扑 / UV，极易破坏权重蒙皮

4. **贴图烘焙 + 纹理绘制** 把高模细节烘焙到低模法线贴图；绘制 PBR 纹理（固有色、粗糙度、金属、AO）

5. **搭建骨骼骨架** 在低模内部摆放人形骨骼链条

6. **蒙皮（骨骼绑定、权重绘制）** 建立骨骼与模型顶点的控制关系，权重修补，旋转四肢测试无撕裂穿模

7. **制作 / 导入动画（K 帧、动作调试）** 姿态模式摆放姿势、打关键帧，制作待机、奔跑、射击等动作

8. **优化、应用变换，导出 FBX 到游戏引擎**

```
雕刻高模 → 重拓扑低模 → UV展开 → 烘焙+绘制纹理 → 创建骨骼 → 蒙皮权重绑定 → 制作动画 → 导出
```

## 方案 B：你当前场景【AI 生成模型流程】（Meshy/Tripo3D 生成模型）

你现在的战术士兵模型属于这一条，直接照着执行：

1. AI 生成原始模型（面数混乱，布线差）
2. **Blender 重拓扑** → 产出干净游戏低模
3. **展开 UV**（必须拓扑完成后操作）
4. AI 生成 PBR 纹理贴图（使用 UV 映射上色）
5. 创建 / 导入骨架骨骼
6. **蒙皮绑定、权重绘制修复**
7. 调试动画、手动 K 帧 / 导入外部动作
8. 导出 FB
