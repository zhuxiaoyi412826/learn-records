# 3D 游戏完整资源分类

（行业通用，适配 Unity / UE5 / Godot）

区分两个维度： 

**美术产出素材（美术团队交付）** 

**工程全量资源（美术 + 策划 + 程序，引擎内全部内容）**

## 一、【美术素材大类（视觉 + 音频资源）】

### 1. 几何网格资源 Mesh（模型）

- **静态模型 StaticMesh**：建筑、地形构件、道具、植被、墙体、场景摆件
- **骨骼网格 SkeletalMesh**：玩家、NPC、怪物、载具、可活动装备
- 附属：LOD 模型、碰撞模型（Collision Mesh）、简化代理模型

### 2. 贴图资源 Texture

独立大类，模型只是形状，贴图是表面信息

- PBR 基础贴图：Albedo 固有色、Normal 法线、Roughness 粗糙度、Metal 金属、AO 环境闭塞
- 光照贴图：Lightmap、Lightprobe 贴图
- 特效专用贴图：渐变、遮罩、噪声、精灵序列帧、光晕贴图
- UI 贴图、图标、蒙版、渲染纹理 RT

### 3. 材质 & Shader

- Material 材质、材质实例 MI
- 自定义 Shader / ShaderGraph / 材质函数
- 专用材质：水体、地形、植被、半透明、自发光、特效加法材质

### 4. 动画资源 Animation

- 骨骼动画片段：行走、攻击、受击、技能、表情动画
- 动画控制器：Animator / AnimationBlueprint (ABP)
- 顶点动画：旗帜飘动、水体波动、布料预烘焙动画
- 摄像机动画、轨道动画、Sequencer 镜头动画

| 子类                              | 说明                           |
| --------------------------------- | ------------------------------ |
| 骨骼动画（Skeletal Animation）    | 角色动作（行走、攻击、待机等） |
| 刚体动画（Legacy Animation）      | 简单物体运动                   |
| 形变动画（Morph/Blend Shape）     | 面部表情、物体变形             |
| 动画控制器（Animator Controller） | 状态机与动画过渡逻辑           |

### 5. 特效资源 VFX

- 粒子系统：公告板粒子、带状拖尾、网格粒子
- 序列帧特效、面片冲击波、能量护盾
- 体积特效、流体爆炸、扭曲特效
- 后处理配置（bloom、泛光、色差、径向模糊等渲染特效）

### 6. 场景 / 地图资源

- 关卡文件（Scene / Map .umap/.tscn）
- 地形数据：高度图、地形分层贴图、植被实例数据
- 光照数据：烘焙光照、探针布局
- 导航网格 NavMesh、寻路区域、阻挡体积

| 子类                 | 说明                   |
| -------------------- | ---------------------- |
| 场景文件             | 关卡整体布局与引用关系 |
| 地形数据             | 高度图、地表材质层     |
| 预制体（Prefabs）    | 可复用的场景对象模板   |
| 导航网格（NavMesh）  | AI 寻路数据            |
| 光照贴图（Lightmap） | 烘焙光照信息           |

### 7. UI 资源

- UI 图集、界面图片、图标、光标
- UI 布局文件、UI 预制体 / UMG 界面
- 字体文件

### 8. 音频资源 Audio

- BGM 背景音乐
- SFX 音效：打击、环境、技能、交互音效
- VO 语音：角色对白、旁白
- 混音配置、音效衰减、音频快照

| 子类          | 说明             | 常见格式      |
| ------------- | ---------------- | ------------- |
| BGM           | 背景音乐         | OGG、MP3、WAV |
| 音效（SFX）   | 动作音效、环境音 | WAV、OGG      |
| 语音（Voice） | 角色配音         | WAV、MP3      |

### 9. 影视资源 Cinematic

- 引擎内实时过场动画（Sequencer/Cinemachine）
- 预渲染视频 CG（mp4/webm 开场动画）

## 二、【策划 & 程序逻辑资源（非美术素材）】

### 1. 数据配置资源

数据表：怪物属性、技能、物品、Buff、任务、掉落、商店、关卡参数 载体：DataTable、ScriptableObject、Json、CSV

### 2. 物理资源

碰撞体、物理材质、布料参数、柔体、关节约束、浮力配置

### 3. 代码 / 逻辑资源/脚本

- C++ / C# / GDScript / 蓝图
- AI 逻辑、战斗系统、交互机关、输入控制系统
- 编辑器拓展工具脚本
- 输入、控制资源  按键映射、手柄配置、震动参数

### 4. 预设资源 Prefab

实体预制体：玩家、怪物、子弹、陷阱、可交互道具

> 预制体本质是**资源组合包**，内部引用模型 / 动画 / 特效 / 脚本

## 三、最简汇总版（方便记忆）

### 美术素材（看得见听得见）

模型、贴图、材质 Shader、动画、特效、场景地图、UI、音频、CG 影片

### 逻辑资源（驱动游戏运行）

数值数据表、脚本 / 蓝图、物理数据、导航数据、预制体、引擎配置

# 2D 游戏资源完整分类

（通用：Cocos、Unity2D、Godot、GameMaker）

**① 美术素材（美术输出）**

**② 项目全量资源（美术 + 策划 + 程序整套工程资源）** 同时和上面 3D 资源做对照，标出 2D 独有的内容、以及 3D 常见但 2D 弱化 / 不存在的资源。

## 一、美术素材资源（可视、可听素材）

### 1. 精灵与图像资源（2D 核心）

1. **静态精灵 Sprite** 角色立绘、道具图标、场景物件、UI 元素
2. **序列帧动画图集** 角色行走、攻击、技能序列帧特效、爆炸动画
3. **TileSet 瓦片图** 地块瓦片、地形瓦片，用于拼接场景地图（横版、像素 RPG 必备）
4. **特效贴图** 光晕、渐变、遮罩、噪波、流光贴图（加法光效、剑气、魔法）
5. **背景图** 远景、中景、近景分层背景（视差滚动背景 Parallax）

> 对应 3D 里的模型 + 贴图；2D 没有 Mesh 网格，全部依靠图片。

| 子类                             | 说明                   | 常见格式       |
| -------------------------------- | ---------------------- | -------------- |
| 精灵（Sprite）                   | 单张角色/物体图片      | PNG、PSD、WebP |
| 精灵图集（Sprite Sheet / Atlas） | 多帧拼接图，用于动画   | PNG + JSON/XML |
| 序列帧（Frame Sequence）         | 逐帧动画的独立图片序列 | PNG            |
| 背景图（Background）             | 场景背景层             | PNG、JPG       |
| 前景/遮罩图                      | 前景遮挡层             | PNG            |

### 2. 动画资源（Spine / DragonBones / Live2D）

- 骨骼切片素材、骨骼绑定数据、动画剪辑
- Live2D：二次元立绘动态、面部表情

> 替代传统逐帧序列帧，减少图片体积 ⚠纯像素小游戏很多不用骨骼动画，只用序列帧

| 子类                           | 说明                                          |
| ------------------------------ | --------------------------------------------- |
| 帧动画（Frame Animation）      | 精灵图集逐帧播放                              |
| 骨骼动画（Skeletal Animation） | 2D 骨骼绑定 + 网格变形（Spine / DragonBones） |
| 补间动画（Tween Animation）    | 位移、缩放、旋转、淡入淡出                    |

### 3. 材质 & Shader

2D 专用着色器： 正常透明、加法混合、变色、溶解、流光、灰度、描边、蒙版裁剪 2D 很少完整 PBR 管线，不存在法线、金属、粗糙度贴图。

### 4. 2D VFX 特效资源

两种主流形式：

1. **序列帧特效**（老 2D、DNF 类、像素游戏）
2. **2D 粒子系统**（点状粒子、拖尾、面片粒子，永远面向屏幕 Billboard） 包含：粒子配置参数、特效图集

### 5. 场景 / 地图资源

- TileMap 瓦片地图数据（瓦片摆放信息）
- 分层背景（视差层）
- 碰撞瓦片、场景触发器位置数据

> 等价 3D 的关卡场景，**没有地形高度图、光照烘焙 Lightmap**

| 子类              | 说明                       |
| ----------------- | -------------------------- |
| 瓦片集（Tileset） | 可拼接的方块图集           |
| 瓦片地图数据      | 地图布局（哪些瓦片放哪里） |
| 碰撞图层          | 标记可碰撞/不可碰撞区域    |

### 6. UI 资源

UI 图集、按钮、弹窗、血条、技能图标、光标 字体文件、文字贴图

### 7. 音频 Audio（和 3D 分类一致）

- BGM 背景音乐
- SFX 音效：打击、技能、环境音效
- VO 角色语音
- 混音配置

### 8. 影片资源

开场 CG、剧情动画（视频文件）

## 二、策划 & 程序逻辑资源（非美术素材，和 3D 大体通用）

### 1. 数值配置表

CSV/Json：怪物属性、技能、物品、掉落、任务、Buff

### 2. 物理与碰撞资源

2D 碰撞形状：矩形、圆形、多边形碰撞体 2D 物理材质、关节、绳索物理

> 区别：3D 是立体碰撞，2D 仅平面碰撞

### 3. 脚本 / 逻辑代码

C# / GDScript / Lua / JS 角色控制、AI、战斗逻辑、交互、UI 逻辑

### 4. 预设 / 场景文件

Unity2D Prefab、Godot .tscn、Cocos 节点预设 玩家、怪物、子弹、可交互物件模板

### 5. 本地化资源

文本表、多语言文案

## 三、最简汇总版（方便记忆）

**2D 美术素材**

精灵图集、瓦片素材、序列帧、骨骼动画资源、背景图、特效贴图、UI 图、字体、音频、视频 CG

**逻辑工程资源**

地图瓦片数据、粒子特效配置、Shader 材质、碰撞数据、数值表格、脚本、场景 / 预设

# 区别

| 资源维度              | 3D 游戏                      | 2D 游戏                         |
| --------------------- | ---------------------------- | ------------------------------- |
| **核心视觉资源**      | 3D 模型 + 材质贴图           | 精灵图 + 精灵图集               |
| **动画方式**          | 骨骼动画 / 形变动画          | 帧动画 / 2D 骨骼动画 / 补间动画 |
| **场景构建**          | 3D 场景 + 地形 + 光照贴图    | 瓦片地图 + 背景图层             |
| **着色器**            | 顶点/片元/计算着色器（复杂） | 较简单（多为 2D sprite shader） |
| **特效**              | 3D 粒子 + 后处理             | 2D 粒子 + 序列帧特效            |
| **导航**              | 导航网格（NavMesh）          | 网格寻路 / A* 格子寻路          |
| **光照**              | 实时光照 + 烘焙光照贴图      | 法线贴图模拟 / 预渲染光影       |
| **音频/字体/UI/脚本** | 基本一致                     | 基本一致                        |

**说明：** 音频、字体、UI、脚本与配置文件在 3D 和 2D 游戏中分类方式基本相同，主要差异集中在**视觉表现资源**（模型 vs 精灵）、**动画体系**和**场景构建方式**上。
