# 注解

## springboot注解分类

按功能分类：**启动配置、Bean 注册、依赖注入、Web 接口、AOP、事务、参数校验、配置读取、MyBatis/MyBatis‑Plus、条件注解**

### 启动

| 注解                       | 作用                                 |
| -------------------------- | ------------------------------------ |
| `@SpringBootApplication`   | 主启动类，复合注解，等价下面三个组合 |
| `@Configuration`           | 标记当前类为配置类，可以写 @Bean     |
| `@EnableAutoConfiguration` | 开启 SpringBoot 自动装配             |
| `@ComponentScan`           | 自动扫描当前包以及子包下所有组件     |

```
@SpringBootApplication
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

```

### 二、注册 Bean（交给 Spring 容器管理）

| 注解              | 作用                                                         |
| ----------------- | ------------------------------------------------------------ |
| `@Component`      | 通用组件，普通工具类                                         |
| `@Service`        | 业务层 Service                                               |
| `@Repository`     | DAO/Mapper 层                                                |
| `@Controller`     | 传统 MVC 控制器，返回页面                                    |
| `@RestController` | 复合 `@Controller+@ResponseBody`；返回 JSON 接口（前后端分离） |
| `@Bean`           | 写在配置类方法上，把方法返回对象注册为 Bean                  |

### 三、依赖注入

| 注解                     | 作用                                                        |
| ------------------------ | ----------------------------------------------------------- |
| `@Autowired`             | 按类型自动注入；可以写字段、构造器、set 方法                |
| `@Qualifier("beanName")` | 配合 @Autowired，按 Bean 名称注入，解决同类型多个 Bean 冲突 |
| `@Resource`              | JSR 规范，优先按名称，其次按类型                            |
| `@Value("${xxx}")`       | 读取 application 配置文件单个属性                           |

### 四、Web 接口（Controller）

| 注解                      | 作用                                 |
| ------------------------- | ------------------------------------ |
| `@RestController`         | 接口返回 JSON                        |
| `@RequestMapping("/api")` | 类 / 方法级别请求路径，支持 get/post |
| `@GetMapping("/list")`    | GET 请求                             |
| `@PostMapping("/submit")` | POST 请求                            |
| `@PutMapping`             | 修改                                 |
| `@DeleteMapping`          | 删除                                 |
| `@RequestBody`            | 接收 POST JSON 请求体                |
| `@RequestParam("name")`   | 接收 url 查询参数 `?name=xxx`        |
| `@PathVariable("id")`     | 路径变量 `/api/{id}`                 |
| `@ResponseBody`           | 返回 JSON 数据；@RestController 自带 |
| `@RequestHeader`          | 获取请求头                           |

```
@PostMapping("/problem/submit")
public ResultVO submit(@RequestBody SubmitDTO dto){
}
```

### 五、配置文件绑定（yml/properties 批量绑定）

| 注解                                                | 作用                                  |
| --------------------------------------------------- | ------------------------------------- |
| `@ConfigurationProperties(prefix = "app.xxx")`      | 批量绑定配置到实体类，prefix 配置前缀 |
| `@EnableConfigurationProperties({XxxConfig.class})` | 开启配置类绑定                        |

### 六、事务注解 Spring‑TX

| 注解             | 作用                                                   |
| ---------------- | ------------------------------------------------------ |
| `@Transactional` | 开启事务；写在 service 方法 / 类上；运行时异常自动回滚 |

注意：**只对 public 方法生效；内部调用 this.xxx () 不会生效**

```
@Transactional(rollbackFor = Exception.class)
public void save(){
}
```

### 七、AOP 切面注解

| 注解              | 作用                         |
| ----------------- | ---------------------------- |
| `@Aspect`         | 标记切面类                   |
| `@Component`      | 切面也要交给 Spring 管理     |
| `@Before`         | 前置通知                     |
| `@After`          | 后置通知                     |
| `@AfterReturning` | 方法正常返回后执行           |
| `@AfterThrowing`  | 抛出异常执行                 |
| `@Around`         | 环绕通知（最强，可拦截前后） |
| `@Pointcut`       | 定义切点表达式               |

### 八、参数校验 JSR303（validation）

需要引入 validation 依赖

| 注解                   | 作用                                  |
| ---------------------- | ------------------------------------- |
| `@Valid`               | 开启实体校验，写在 @RequestBody 前面  |
| `@NotNull`             | 不能为 null                           |
| `@NotBlank`            | 字符串不能 null、不能空串、不能全空格 |
| `@NotEmpty`            | 集合不能 null，size>0                 |
| `@Size(min=1,max=100)` | 字符串 / 集合长度范围                 |
| `@Min @Max`            | 数字大小                              |
| `@Pattern(regexp="")`  | 正则校验                              |

### MyBatis / MyBatis‑Plus

| 注解                            | 作用                                |
| ------------------------------- | ----------------------------------- |
| `@Mapper`                       | 标记 Mapper 接口，交给 mybatis 扫描 |
| `@MapperScan("com.xxx.mapper")` | 启动类，批量扫描 mapper 包          |
| `@TableName("sensitive_word")`  | MP 实体类，对应数据库表名           |
| `@TableId(type = IdType.AUTO)`  | 主键策略，自增                      |
| `@TableField("word")`           | 数据库字段映射                      |

### 十、条件装配注解（满足条件才创建 Bean）

| 注解                                                         | 作用                     |
| ------------------------------------------------------------ | ------------------------ |
| `@ConditionalOnClass(X.class)`                               | 类路径存在才创建 Bean    |
| `@ConditionalOnMissingBean`                                  | 容器不存在该 Bean 才创建 |
| `@ConditionalOnProperty(prefix="xxx",name="enable",havingValue="true")` | 配置文件为 true 才生效   |

### 十一、定时任务

| 注解                               | 作用                                    |
| ---------------------------------- | --------------------------------------- |
| `@EnableScheduling`                | 启动类开启定时任务支持                  |
| `@Scheduled(cron = "0 0 * * * ?")` | cron 表达式定时；fixedRate 固定间隔毫秒 |

### 十二、生命周期相关

| 注解             | 作用                        |
| ---------------- | --------------------------- |
| `@PostConstruct` | Bean 初始化完成之后执行方法 |
| `@PreDestroy`    | Bean 销毁之前执行           |

### 十三、全局异常 / 统一返回

| 注解                                 | 作用                                                |
| ------------------------------------ | --------------------------------------------------- |
| `@RestControllerAdvice`              | 全局异常处理器，组合 @ControllerAdvice+ResponseBody |
| `@ExceptionHandler(Exception.class)` | 捕获指定异常                                        |

## 其他注解

### 1. 基础通用注解

| 注解                       | 作用                                                         | 典型场景                         |
| -------------------------- | ------------------------------------------------------------ | -------------------------------- |
| `@Override`                | 编译期校验：标记方法重写父类 / 实现接口方法，签名错误会编译报错 | 实现接口方法、重写父类逻辑       |
| `@Deprecated`              | 标记类 / 方法 / 字段已废弃，调用时编译器弹出警告             | 旧接口下线，提示开发者使用新方案 |
| `@SuppressWarnings("xxx")` | 抑制编译器警告，常用值：`unchecked`、`unused`、`rawtypes`    | 消除泛型未检查、变量未使用的警告 |
| `@FunctionalInterface`     | 标记接口为**函数式接口**（仅允许 1 个抽象方法），配合 Lambda 表达式使用 | 自定义回调接口、线程任务接口     |
| `@SafeVarargs`             | 抑制泛型可变参数的编译警告，仅用于 final /static/private 方法 | 泛型可变参数工具方法             |

### 2. 元注解（自定义注解的 “注解”）

| 注解                              | 作用                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| `@Target(ElementType.xxx)`        | 指定注解可以标注的位置：`TYPE`类、`METHOD`方法、`FIELD`字段、`PARAMETER`参数 |
| `@Retention(RetentionPolicy.xxx)` | 注解保留周期：`SOURCE`仅源码、`CLASS`编译期、`RUNTIME`运行期（业务自定义注解一般用 `RUNTIME`） |
| `@Documented`                     | 标记注解会被生成到 JavaDoc 文档中                            |
| `@Inherited`                      | 标记注解可以被子类继承                                       |

### 二、Java Web 原生注解（Servlet 3.0+ 规范）

| 注解                   | 作用                                                       |
| ---------------------- | ---------------------------------------------------------- |
| `@WebServlet("/path")` | 标记类为 Servlet，替代 web.xml 配置请求路径                |
| `@WebFilter("/*")`     | 标记类为过滤器，配置拦截路径，替代 web.xml 注册 Filter     |
| `@WebListener`         | 标记类为 Web 监听器，比如监听上下文启动、请求创建销毁      |
| `@MultipartConfig`     | 标记 Servlet 支持文件上传，处理 `multipart/form-data` 表单 |
| `@ServletSecurity`     | Servlet 级别的安全权限约束                                 |

## Spring / SpringBoot 进阶补充注解

**1.Bean作用域**

| 注解            | 作用                                                         |
| --------------- | ------------------------------------------------------------ |
| `@Scope("xxx")` | 指定 Bean 作用域：`singleton`单例（默认）、`prototype`多例、`request`请求级、`session`会话级 |
| `@Lazy`         | 懒加载：容器启动时不创建 Bean，第一次使用时才实例化          |
| `@Primary`      | 同类型存在多个 Bean 时，标记该 Bean 为优先注入项             |
| `@Order(num)`   | 控制多个 Bean / 过滤器 / 切面的执行顺序，数字越小优先级越高  |

**2.多环境配置**

| 注解                                          | 作用                                              |
| --------------------------------------------- | ------------------------------------------------- |
| `@Profile("dev/test/prod")`                   | 标记类 / 方法仅在指定环境生效，多环境切换核心注解 |
| `@PropertySource("classpath:xxx.properties")` | 加载额外的 properties 配置文件                    |
| `@Import({XxxConfig.class})`                  | 导入其他配置类，拆分多个配置模块时使用            |
| `@ImportResource("classpath:spring.xml")`     | 兼容传统 Spring XML 配置文件                      |

**3.SpringMVC补充**

| 注解                              | 作用                                               |
| --------------------------------- | -------------------------------------------------- |
| `@CrossOrigin`                    | 类 / 方法级别开启跨域，快速解决前后端联调跨域问题  |
| `@CookieValue("name")`            | 获取请求中指定 Cookie 的值                         |
| `@ModelAttribute`                 | 预先绑定数据到 Model，当前 Controller 所有方法共享 |
| `@SessionAttributes("key")`       | 将 Model 数据存入 Session 域                       |
| `@ResponseStatus(HttpStatus.xxx)` | 指定方法 / 异常返回的 HTTP 状态码                  |
| `@RequestPart`                    | 处理文件上传请求，绑定 multipart 文件对象          |

**4.异步缓存增强**

| 注解                                       | 作用                                                         |
| ------------------------------------------ | ------------------------------------------------------------ |
| `@EnableAsync`                             | 启动类开启异步方法支持                                       |
| `@Async`                                   | 标记方法异步执行（独立线程池），适合耗时操作（发邮件、统计计算、异步生成题目） |
| `@EnableCaching`                           | 启动类开启 Spring 缓存注解                                   |
| `@Cacheable(value="cacheName", key="#id")` | 方法结果缓存，同参数下次请求直接读缓存，不执行方法（适合缓存题目详情、热点数据） |
| `@CacheEvict`                              | 清除指定缓存，数据更新时调用                                 |
| `@CachePut`                                | 更新缓存，不影响方法执行                                     |

## 第三方注解

**1.Lombok注解**

| 注解                  | 作用                                                         |
| --------------------- | ------------------------------------------------------------ |
| `@Data`               | 类级别，一键生成 Getter、Setter、toString、equals、hashCode、无参构造 |
| `@NoArgsConstructor`  | 生成无参构造方法                                             |
| `@AllArgsConstructor` | 生成全参构造方法                                             |
| `@Builder`            | 开启构建者模式，链式创建对象                                 |
| `@Slf4j`              | 类级别自动生成日志对象 `log`，直接 `log.info()`/`log.error()`，不用手动写 LoggerFactory |

**2.jackson JSON序列化**

| 注解                                                         | 作用                                                     |
| ------------------------------------------------------------ | -------------------------------------------------------- |
| `@JsonFormat(pattern="yyyy-MM-dd HH:mm:ss", timezone="GMT+8")` | 日期格式化，统一返回前端的时间格式                       |
| `@JsonIgnore`                                                | 序列化时忽略字段，不返回给前端（比如密码、内部敏感字段） |
| `@JsonProperty("alias")`                                     | 指定字段序列化后的 JSON 键名                             |
| `@JsonInclude(Include.NON_NULL)`                             | 字段为 null 时不序列化，精简返回结果                     |



- **接口文档**：Swagger/OpenAPI 注解 `@Api`、`@ApiOperation`、`@ApiModelProperty`，自动生成在线接口文档。
- **校验补充**：`@Email`、`@Length`、`@Range`，扩展参数校验能力。
- **MyBatis 注解 SQL**：`@Select`、`@Insert`、`@Update`、`@Delete`，简单 SQL 不用写 XML 文件。
