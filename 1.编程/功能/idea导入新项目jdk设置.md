# jdk版本设置

| 位置                    | 作用                                         |
| ----------------------- | -------------------------------------------- |
| 项目结构‑项目 SDK       | IDE 源码解析、代码提示                       |
| 模块 SDK + 模块语言级别 | 模块源码语法检查                             |
| Java 编译器‑字节码版本  | javac 编译 class 版本                        |
| Maven 运行时 JRE        | IDEA 内部 mvn 命令执行用的 JDK（非常容易忘） |
| 运行配置 JRE            | spring‑boot:run 运行服务使用的 JDK           |
