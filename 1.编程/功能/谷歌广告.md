# 谷歌广告（搜索 / 展示），把流量引到你的网站 → 用 Google Ads + 网站装追踪代码

### 一、先搞清楚：谷歌展示广告（Display）是什么

- 投放在**谷歌联盟网站、App、YouTube、Gmail**上的图文 / 视频广告
- 按 **CPC（按点击）/CPM（按千次曝光）** 计费
- 适合：**品牌曝光、再营销、拉新**；不适合纯 “高意图成交” 搜索词

------

### 二、接入前必备条件（缺一不可）

1. **独立网站 / 落地页**（必须 HTTPS、可访问、有明确转化入口：表单 / 电话 / 购买）
2. **干净的 Gmail 账号**（专门管广告，别和私人邮箱混用，降低风控）
3. **双币信用卡（Visa/MasterCard）**（用于扣费，不支持微信 / 支付宝直充）
4. **谷歌账号能正常访问谷歌服务**（你懂的）

------

### 三、第一步：开通 Google Ads 账户（10 分钟）

1. 访问：**[ads.google.com](https://ads.google.com)** → 点 “立即开始”

2. 用准备好的 Gmail 登录 → 选择**专家模式**（关键！别用简化模式）

3. 选**仅创建账号（不创建广告系列）**

4. 填写：

   - 商家名称（品牌 / 公司名）
   - 网站 URL（HTTPS，必须能打开）

   

5. 选择币种：**USD（美元，推荐）** 或 CNY（人民币），**一旦选定不可修改**

6. 绑定付款方式：填信用卡信息 → 提交审核（一般**1–2 天**通过）

------

### 四、第二步：准备展示广告素材（核心！）

展示广告靠**图 + 短文案**抓人，尺寸多，建议先做**3 套核心尺寸**：

#### 1. 必做尺寸（覆盖 90% 流量）

- **300×250**（中矩形，移动端 / 站内最常见）
- **728×90**（页头横幅，PC 端）
- **160×600**（侧边竖幅，PC 端）

#### 2. 素材规范

- 图片：**高清无水印、无违规内容**（成人 / 医疗 / 敏感词直接拒）
- 文案：**标题≤25 字、描述≤70 字**，含核心卖点 + 行动号召（如 “免费试用”“限时折扣”）
- 格式：JPG/PNG，单图≤150KB；视频≤30 秒（可选）

------

### 五、第三步：创建展示广告系列（20 分钟）

#### 1. 新建广告系列

- 左侧菜单 → **广告系列** → **+** → 选**展示广告（Display）**
- 目标选：**销售 / 潜在客户 / 网站流量**（按你的需求）

#### 2. 定向设置（决定流量质量，别乱投！）

- **地理位置**：精准到**国家 / 城市 / 半径**（别投全球，浪费钱）

- **语言**：和你的网站 / 受众语言一致（如英语 / 西班牙语）

- 受众（核心）

  ：

  - **再营销（优先）**：给**访问过你网站的人**投（转化率最高）
  - **兴趣定向**：选和产品相关的兴趣（如 “健身”“母婴”）
  - **关键词定向**：填和业务相关的关键词（如 “buy running shoes”）

  

#### 3. 预算 & 出价（新手保守！）

- **日预算**：**$20–$50**（先跑 7 天看数据，别一开始投大预算）
- **出价策略**：新手选**手动 CPC**（可控，避免 AI 乱花）；有 30 + 转化后再换**tCPA/tROAS**

#### 4. 上传素材 & 写文案

- 上传准备好的**3 套尺寸图片**
- 填标题、描述、显示 URL → 预览效果 → 保存

------

### 六、第四步：安装转化追踪（必须！否则白投）

你需要在网站埋**谷歌 Ads 转化代码**，用来统计：**表单提交、电话点击、购买**等关键动作。

#### 1. 创建转化目标

- Google Ads 后台 → **工具与设置** → **转化** → **+**
- 选转化类型：**网站（表单 / 购买）/ 电话**
- 填转化名称（如 “表单提交”）、价值（如 “¥100”）→ 生成代码

#### 2. 安装代码（2 种方法）

- 方法 A（新手）：用**Google Tag Manager（GTM）**，复制代码到 GTM，再安装 GTM 到网站
- 方法 B（技术）：直接把代码粘贴到网站 **</body>前 **，或对应按钮点击事件里

#### 3. 验证

- 安装后**24 小时**内，在 Google Ads 后台看 “转化” 是否显示**有效**

------

### 七、第五步：上线 & 优化（长期动作）

#### 1. 上线

- 检查所有设置：**定向、预算、素材、转化代码** → 开启广告系列
- 前 7 天：**只观察，别大改**，收集数据（曝光、点击、点击率、转化）

#### 2. 核心优化（每周 1 次）

- **停掉低效流量**：点击率 < 0.1%、CPC 过高的广告 / 定向直接暂停
- **优化素材**：保留**点击率最高**的 3 套图，删掉差的；每周上新 2 套
- **调整出价**：转化好的关键词 / 受众**加价 10%**，差的**降价 / 暂停**
- **加否定定向**：排除无效流量（如 “free”“cheap”“job”）

------

### 八、常见坑（新手必避！）

1. **网站不合规**：没 HTTPS、打不开、没隐私政策 → 直接拒登
2. **素材违规**：成人、医疗、虚假宣传、版权图 → 账号被封
3. **预算乱设**：日预算 $100+ → 几天花光，没数据优化
4. **不装转化追踪**：不知道谁点了、谁成交 → 钱花得不明不白
5. **定向太宽**：投全球 + 所有兴趣 → 垃圾流量多，转化率低

# 网站接入 Google AdSense 赚钱 完整一步一步教程（新手直接照做）

## 一、先硬性条件（不满足百分百过不了审核）

1. 有**独立顶级域名**（[xxx.com](https://xxx.com)），免费二级域名不行
2. 网站必须 **HTTPS** 正常打开、能全球访问
3. 网站内容：**原创文章至少 10 篇以上**，每篇 300 字 +
4. 必须有 3 个页面：**关于我们、联系我们、隐私政策**
5. 不能有：盗版、破解、色情、赌博、私服、侵权影视小说

## 二、注册 Google AdSense 账号

1. 打开官网：https://adsense.google.com

2. 用**干净全新 Gmail 账号**登录（别用乱注册、用过违规项目的号）

3. 选择：**我是发布商**

4. 填写资料：

   - 网站地址：填完整 https://xxx.com
   - 国家：选 **中国**
   - 姓名、地址填**真实可收信件的地址**（后面收 PIN 码打款用）

   

## 三、给网站安装 AdSense 验证代码（关键）

后台会给你一段代码，格式长这样：

html



预览







```
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js"></script>
<script>
(adsbygoogle = window.adsbygoogle || []).push({
  google_ad_client: "ca-pub-xxxxxxxxxxxxxxxx"
});
</script>
```

### 安装位置

把代码粘贴到你网站**所有页面的 <head> 标签里面**

### 不同网站安装方法

1. **WordPress**

   安装插件：`Insert Headers and Footers`

   把代码贴到 **Header** 保存即可，全站自动生效

   

2. **宝塔自建网站 / 源码**

   找到模板 `header.html` 或 `index.html`

   放到 `<head>` 和 `</head>` 中间

   

3. **凡科 / 建站模板**

   后台找到「自定义头部代码」直接粘贴

   

## 四、提交审核

1. 代码装完回到 AdSense 后台
2. 点击「我已将代码放置在网站上」提交审核
3. 等待审核：**3~15 天**不等

### 审核期间不要做

- 不要自己点自己网站广告
- 不要刷流量、买流量
- 不要大量改网站模板、删文章
- 不要放违规内容

## 五、审核通过后：创建广告位赚钱

1. 后台点 **广告 → 广告单元**

2. 新建广告，推荐 3 种最赚钱尺寸：

   - 300×250 文章中间 / 侧边
   - 728×90 网站顶部横幅
   - 自适应信息流 文章首尾

   

3. 生成广告代码，复制

4. 粘贴到你网站想展示的位置（侧边栏、文章结尾、首页中间）

## 六、收款门槛

1. 收益达到 **10 美元** 谷歌寄 PIN 码信件到你填写地址
2. 输入 PIN 验证身份
3. 达到 **100 美元** 自动月结打款
4. 国内可以用**中行 / 工行等银行卡**收款

## 七、必避坑（封号大忌）

1. 自己手动点广告、叫朋友帮点 → 直接永久封号
2. 刷流量、买虚假访客 → 封号
3. 网站内容抄袭、搬运、盗版资源 → 不通过 + 封号
4. 放成人、博彩、私服、破解资源 → 直接封号

# 国内双币卡？大白话讲清楚

## 1. 最简单定义

**国内双币卡 = 一张卡里有两个钱包**

- 一个：**人民币钱包（银联）** 👉 国内超市、微信支付宝、国内刷卡用
- 一个：**外币钱包（Visa 或 MasterCard）** 👉 注册谷歌广告、外网付费、海淘、境外网站扣费用

卡面上一定同时有两个标志：

**银联 + Visa**  或者  **银联 + MasterCard**

## 2. 和普通银行卡的区别

- 普通储蓄卡 / 信用卡：**只有银联标志** → 只能国内用，**绑不了谷歌广告、付不了境外网站**
- 双币卡：**银联 + Visa/Master** → 国内能刷、**国外境外网站也能直接扣费**

## 3. 分两种：双币信用卡、双币借记卡

### ① 双币信用卡（最常用、绑谷歌广告首选）

银行给你额度，先消费后还款，卡面有：**银联 + Visa/Master**

中行、工行、建行、招行、交行都有。

### ② 双币借记卡（储蓄卡类型）

自己存钱进去才能花，也带 **银联 + Visa/Master**，也能绑谷歌，但不如信用卡稳。

## 4. 重点：能不能用来开谷歌 ED 广告？

✅ **国内正规银行的双币 Visa/Master 卡，完全可以绑 Google Ads**

只需要多开一个功能：**境外无卡支付 / 网上境外交易**

❌ 只有银联标志的普通卡：**百分百不能用**

## 5. 一眼分辨是不是双币卡

拿出银行卡看正面 logo：

- 只看到：**银联** → 单币卡，不行
- 看到：**银联 + Visa** 或 **银联 + MasterCard** → 就是双币卡，能用
