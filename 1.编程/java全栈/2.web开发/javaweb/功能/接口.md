### 1.规范的 Controller 里面该有什么

核心原则：**Controller 只做请求接收、参数校验、调用 Service、返回结果；业务逻辑、数据库操作一律不许写在 Controller**

### 2. 接口方法（每个方法对应一个 API 接口）

每个接口方法固定 4 件事：

1. 接收前端传过来的参数（`@RequestParam`、`@RequestBody`、`@PathVariable`）
2. 简单参数校验（非空、格式，复杂校验丢 Service）
3. 调用 Service 的业务方法
4. 返回统一响应对象 `Result<T>`
