## 一、理解 Skill 的基本结构

一个 Skill 本质上是一个**包含 `SKILL.md` 文件的文件夹**，采用渐进式披露的三层架构 

：





```
my-search-skill/
├── SKILL.md          # 【必需】核心指令文件（YAML 元数据 + Markdown 正文）
├── scripts/          # 【可选】可执行脚本（Python/Bash 等）
├── references/       # 【可选】参考文档（按需加载）
└── assets/           # 【可选】模板、资源文件
```

**三层加载机制** 

：



- **L1 元数据层**（~100 token）：仅加载 `name` 和 `description`，用于技能发现与匹配
- **L2 指令层**（<5000 token）：技能被激活时加载完整 `SKILL.md` 正文
- **L3 资源层**（按需加载）：执行过程中按需读 `scripts/`、`references/` 等

## 二、全文搜索 Skill 的核心设计思路

### 1. 定义清晰的能力边界

一个全文搜索 Skill 通常需要覆盖以下能力 

：



表格





| 能力           | 说明                                       |
| -------------- | ------------------------------------------ |
| **关键词检索** | 根据用户输入的关键词在目标内容中搜索匹配项 |
| **高级筛选**   | 支持时间范围、文件类型、来源等条件过滤     |
| **结果排序**   | 按相关度、时间等维度排序                   |
| **上下文预览** | 返回命中关键词前后的上下文片段             |
| **结构化输出** | 将搜索结果整理为规范格式                   |

### 2. 设计原则

**① 描述精准（description）**：description 决定 AI 是否触发该 Skill，必须包含触发关键词和场景 

。





```
description: 在本地/指定路径的文档中执行全文搜索，支持关键词匹配、上下文预览和结果排序。
当用户说"搜索""查找""检索""全文搜索""找文档""搜内容"时触发。
```

**② 流程清晰**：用编号列表明确步骤顺序 

：





```
## 执行步骤
1. 从用户输入中提取搜索关键词和范围参数
2. 确定搜索路径和文件类型限制
3. 执行全文搜索（关键词匹配 + 上下文提取）
4. 按相关度排序并去重结果
5. 输出结构化搜索结果列表
```

**③ 边界明确**：告诉 AI 遇到特殊情况怎么处理 

：





```
## 异常处理
- 搜索路径不存在时：提示用户并提供可选路径
- 搜索结果为空时：建议用户更换关键词或扩大范围
- 文件无权限读取时：跳过并记录，不中断搜索
```

### 3. 选择合适的 Skill 设计模式

根据任务特征，全文搜索适合以下模式 

：



**模式一：Navigator（条件路由）**——当搜索涉及多个数据源时



```
用户输入 → 判断搜索范围
           ├─ 本地文件 → 执行本地全文搜索
           ├─ 知识库    → 执行语义检索
           └─ 网络      → 执行联网搜索
```

**模式二：线性流程**——当搜索路径明确时 

：





```
Step 1: 解析查询参数 → Step 2: 执行搜索 → Step 3: 筛选结果 → Step 4: 输出报告
```

**模式三：工具封装器**——当搜索依赖专用工具/脚本时 

：



yaml



```
allowed-tools: Read, Grep, Glob, Bash
```

将搜索的逻辑封装到 `scripts/` 中，SKILL.md 只定义"做什么"，脚本负责"怎么做" 

。



## 三、SKILL.md 完整示例框架

yaml



```
---
name: fulltext-search
description: 在本地文档或指定路径中执行全文搜索，支持关键词匹配、上下文预览和结果排序。
当用户说"搜索""查找""检索""全文搜索""帮我找""搜一下""搜内容"时触发。
metadata:
  version: 1.0.0
  pattern: linear-flow
allowed-tools: Read, Grep, Glob
---

# 全文搜索 Skill

## 执行步骤

1. **解析搜索请求**
   - 从用户输入中提取搜索关键词
   - 确认搜索范围（默认当前工作目录，支持用户指定路径）
   - 确认文件类型过滤条件（如 `.md`、`.txt`、`.pdf` 等）

2. **执行全文搜索**
   - 在指定范围内递归搜索包含关键词的所有文件
   - 对每个匹配结果，提取关键词前后的上下文片段（前后各 50 字）
   - 记录文件路径、匹配行号、上下文片段

3. **结果处理**
   - 按匹配次数从高到低排序
   - 去除重复或高度相似的结果
   - 若结果超过 20 条，分页展示

4. **输出结构化结果**
   - 显示搜索摘要（总匹配数、搜索范围、耗时）
   - 列出每条结果：文件路径 + 匹配行号 + 上下文片段
   - 提示用户可进一步操作（如"打开文件""缩小范围""换关键词"）

## 约束规则

- 禁止搜索 `node_modules/`、`.git/`、`__pycache__/` 等系统目录
- 搜索关键词为空时，提示用户输入关键词
- 二进制文件自动跳过，不尝试全文匹配
- 对于大文件（>10MB），仅搜索前 10000 行

## 输出格式

​```markdown
## 搜索结果
关键词: [关键词]
搜索范围: [路径]
共找到 [N] 条结果

### 结果 1
📄 `文件路径` (第 X 行)
... 上下文片段 ... **[关键词]** ... 上下文片段 ...

### 结果 2
...
```
