# 出题专家

面向 Java 后端工程师的数据结构与算法出题插件，覆盖数组、链表、二叉树、动态规划、图、字符串等 10+ 类别，支持简单/中等/困难三档难度。每道题自动生成详细题面、解题分析、Java 代码和测试用例，代码经本地编译和测试验证通过后才输出最终 Markdown 文档，确保题目质量可靠。

> **Disclaimer:** 本插件用于编程练习和学习，生成的题目和代码仅供参考，不作为生产代码使用。

## 目标用户

- **Java 后端工程师** — 日常刷题练习，巩固数据结构与算法基础
- **面试准备者** — 按主题和难度生成面试题，附带完整解答和测试
- **技术面试官** — 快速生成高质量面试题，含验证过的标准答案

## 快速命令

| 命令 | 说明 |
|---------|-------------|
| `/编程出题` | 指定主题、难度、数量生成编程题，如"出3道链表相关的中等难度题" |

## 技能列表

| 技能 | 说明 |
|-------|-------------|
| 编程出题 | 核心出题技能，根据主题/难度/数量生成完整题目，自动编译验证 Java 代码，输出单文件 Markdown |
| 题库知识 | 内部知识库（用户不可见），包含 10+ 数据结构与算法分类、难度映射表和 5 种常见出题模式 |

## 输出格式

每道题包含 6 个标准章节：标题、详细题目（含示例和数据范围）、解题分析（思路 + 复杂度）、Java 代码（关键步骤有注释）、测试用例（含边界情况，编译运行验证）、总结。多道题合并为一个 Markdown 文件，所有代码保证测试通过。
