# 流

## 二、Stream 流（JDK8+，java.util.stream，集合流式）✅

> ❗**不是 IO！和文件读写没关系！** 一句话定义：**对集合 / 数组的数据，做过滤、映射、排序、归约的处理流水线。** 思想：**把集合中数据看做流上的数据，中间链式加工，最终得到结果。** 分为：**中间操作（延迟，返回新 Stream）、终结操作（触发执行）**

### ✅外部迭代（External iteration）

**由我们开发者自己控制循环。** 我们维护迭代器、for 循环、while，手动控制 “什么时候取下一个元素，什么时候结束”。 属于**命令式编程**。

```
public class Randoms {
    public static void main(String[] args){
        new Random(147)
                .ints(5,20)
                .distinct()
                .limit(7)
                .sorted()
                .forEach(System.out::println);
    }

}
```

### ✅内部迭代（Internal iteration）

**迭代的控制逻辑被封装到库内部了！我们不再获取迭代器。** 我们只传入处理逻辑（lambda）；**遍历、循环由集合 / Stream 库内部完成**。 属于**声明式编程**。

```
public class ImperativeRandoms {
    public static void main(String[] args) {
        Random rand = new Random(47);
        SortedSet<Integer> rinst = new TreeSet<>();
        while(rinst.size( )<7){
            int r = rand.nextInt(20);
            if(r < 5) continue;
            rinst.add(r);
        }
        System.out.println(rinst);
    }
}
```
