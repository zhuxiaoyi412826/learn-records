# AI日报生成器

> 一键生成高质量AI行业新闻日报，从话题追踪到公众号发布全流程自动化。

## 技能概述

本技能整合了AI日报生成的完整工作流：从每日AI话题追踪获取热点事件，生成爆款标题，撰写深度分析文章，进行质量评分优化，生成赛博科技风封面图，创建公众号草稿，到最终邮件通知。适用于AI领域内容创作者、公众号运营者、行业分析师等人群。

**核心能力：**
- 📰 话题追踪：自动获取当日AI领域热点事件，确保内容时效性
- 🔥 爆款标题：基于公众号爆款规律生成高点击率标题
- ✍️ 深度撰文：每个事件独立成节，包含背景、细节、影响分析
- 📊 质量评分：多维度自动评分（标题/结构/可读性/互动），低于75分自动优化
- 🎨 封面生成：赛博科技风公众号封面（2.35:1比例）
- 📱 公众号发布：一键创建草稿，规范HTML排版
- 📧 邮件通知：自动发送到指定邮箱

## 工作流程

### 第一步：确认配置与参数

执行前先确认以下参数，未明确指定时使用默认值：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 日期 | 今日 | 日报对应的日期，格式YYYY-MM-DD |
| 输出目录 | ./AI日报/{日期}/ | 所有产物存放目录 |
| 文章字数 | ≥3500字 | 正文最低字数要求 |
| 质量达标线 | 75分 | 综合评分低于此值需优化 |
| 事件数量 | 3-5个 | 覆盖的热点事件数 |
| 封面风格 | 赛博科技风 | 深蓝黑底+霓虹蓝紫光效+AI元素 |
| 公众号排版 | 白底左对齐 | 标题蓝色加粗，正文行高2.0首行缩进 |
| 收件邮箱 | 从配置读取 | 日报通知邮箱 |

> 注意：使用前请确保已配置微信公众号凭证（AppID + AppSecret）和收件邮箱。

---

### 第二步：话题追踪

调用话题追踪能力，获取当日AI领域热点事件。

**执行要点：**
1. 聚焦AI领域：大模型、AI应用、算力、行业政策、创业融资等
2. 权威性要求：优先采信官方发布、权威媒体、企业公告
3. 事件筛选标准：
   - 行业影响力大（头部企业、重要政策、重大突破）
   - 信息来源可靠（至少2个独立信源交叉验证）
   - 当日或近24小时内发生
4. 输出格式：每个事件包含「事件标题」「核心摘要」「来源链接」「重要性评级」

**验收标准：** 至少获取3-5个高质量事件，覆盖不同细分领域

---

### 第三步：爆款标题生成

基于当日核心事件生成3-5个备选标题，选定最佳标题。

**标题规则：**
- 字数：14-22字最佳（公众号展示最优长度）
- 要素：包含数字 + 冲突/悬念 + 直击利益点
- 风格：公众号爆款风格，避免纯新闻播报式
- 类型：
  - 悬念型："…背后，藏着什么真相？"
  - 冲突型："刚宣布就反转，比你想的更残酷"
  - 数字型："3个信号看懂…"
  - 观点型："别只看表面——…的3个真相"

**爆款标题检查清单：**
- ✅ 有具体数字（增强数据感）
- ✅ 有情绪钩子（问号/感叹号/冲突词）
- ✅ 直击读者利益（对读者有什么影响）
- ❌ 避免"宣布""发布""推出"等新闻式动词堆砌

---

### 第四步：深度文章撰写

基于筛选出的事件撰写完整的深度分析文章。

**文章结构：**

```
# {主标题}

## 今日导读
100字左右总览今日核心事件，引出下文

## 01 {事件一标题}
### 事件背景
交代事件来龙去脉，相关企业/人物背景
### 核心细节
事件的具体内容、关键数据、时间线
### 影响分析
对行业、对企业、对从业者的影响
### 未来展望
趋势判断、后续发展可能性

## 02 {事件二标题}
（同上结构）

## 03 {事件三标题}
（同上结构）

…（可扩展到4-5个事件）

## 总结
归纳当日核心看点，提炼行业趋势判断

> 参考资料：
> 1. [来源名称](链接)
> 2. [来源名称](链接)
```

**写作要求：**
1. 每个事件不少于600字，全文不少于3500字
2. 加入观点性表达："这说明什么""本质是""底层逻辑""值得注意的是"
3. 运用数据支撑：具体数字、对比数据、增长比例
4. 段落简短：每段控制在3-5行，适合手机阅读
5. 加粗重点：核心观点、关键数据用加粗标出
6. 口语化过渡："什么概念？""你发现没有""说白了"等节奏词
7. 参考资料不超过3个，优先选择最权威来源

---

### 第五步：质量评分与优化

使用质量分析工具对文章进行多维度评分，低于75分自动优化。

**评分维度：**

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 标题吸引力 | 30% | 长度、情绪钩子、数字、冲突感 |
| 内容结构 | 25% | 开头钩子、段落长度、重点加粗、结尾CTA |
| 可读性 | 20% | 平均句长、长句占比、术语密度、口语化过渡 |
| 互动吸引力 | 25% | 观点密度、数据支撑、对比冲突、递进结构 |

**优化流程：**
1. 运行分析脚本获取综合评分
2. 如评分≥75分，进入下一步
3. 如评分<75分，根据优化建议逐条修改：
   - 标题优化：调整长度、增加钩子、加入数字
   - 结构优化：拆分长段、增加加粗、加入CTA
   - 可读性优化：拆分长句、解释术语、加入过渡词
   - 互动优化：增加观点、补充数据、加强对比
4. 修改后重新评分，直至≥75分或最多优化2轮

---

### 第六步：封面图生成

生成符合公众号规格的封面图。

**规格要求：**
- 比例：2.35:1（公众号封面标准比例）
- 尺寸：建议1280×544像素以上
- 风格：赛博科技风

**视觉元素：**
- 背景：深蓝黑底 + 霓虹蓝紫渐变光效
- 元素：芯片、神经网络、数据流、电路纹理、AI标识
- 文字：包含文章主标题（高对比度、醒目）
- 整体：未来感、科技感、冲击力

**注意：** 封面图需清晰、有设计感、贴合当日文章主题，避免文字过多或过小。

---

### 第七步：公众号草稿创建

将文章转换为规范的HTML格式，上传到微信公众平台草稿箱。

**HTML排版规范：**

| 元素 | 样式 |
|------|------|
| 整体 | 白底左对齐，宽度100%，模块化布局 |
| 小节标题 | 颜色#2563EB，加粗，18px，margin-top: 30px，编号01/02/03格式 |
| 正文 | 颜色#333333，16px，行高2.0，首行缩进2em，margin: 6px 0 |
| 段落间距 | 使用`<p style="height:4px;"></p>`做段间距 |
| 加粗重点 | `<strong>`标签，颜色同正文 |
| 参考资料 | 灰色小字#999999，13px，margin: 8px 0 |
| 结尾引导 | 加粗，引导关注/留言/转发 |

**发布流程：**
1. 将Markdown文章转换为符合规范的HTML
2. 将封面图上传到微信素材库，获取media_id
3. 调用草稿箱接口创建草稿
4. 返回草稿链接和media_id

**关键注意事项：**
- 中文编码必须使用UTF-8，避免乱码
- 封面图大小控制在2MB以内
- 确保IP在公众号白名单内

---

### 第八步：邮件通知

将生成的日报内容通过邮件发送给指定收件人。

**邮件格式：**
- 主题：「AI日报」{日期} - {文章标题}
- 正文：纯文本格式，包含文章全文
- 附件：可选，包含Markdown原文和封面图

**注意事项：**
- 优先使用纯文本格式，避免被邮件服务商拦截
- 确保邮件内容完整，格式清晰可读
- 发送成功后通知用户

## 常见问题处理

### Q: 话题追踪结果质量差怎么办？
A: 调整筛选标准，提高权威性要求；如事件数量不足，扩大检索范围到近48小时。

### Q: 文章评分总是不达标怎么办？
A: 优先优化权重最高的维度（标题30% + 互动25%），每轮优化聚焦1-2个核心问题，最多优化2轮。

### Q: 公众号API调用失败怎么办？
A: 检查：①access_token是否过期 ②IP是否在白名单 ③图片大小是否超限 ④编码是否为UTF-8

### Q: 封面图生成不满意怎么办？
A: 调整prompt，明确描述期望的视觉风格和元素；可多次生成选择最佳版本。
