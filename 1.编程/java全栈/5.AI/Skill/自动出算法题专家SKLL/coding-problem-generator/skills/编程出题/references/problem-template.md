# 题目输出模板

每道题严格按照以下 7 个章节输出，多道题合并到一个 Markdown 文件中。简单难度可省略"多解法对比"章节。
题号使用全局递增编号，从 problem_history.json 中读取 lastId，新题从 lastId + 1 开始。

---

## 文件整体结构

```markdown
# 数据结构与算法编程题 — #{起始题号}-{结束题号}

> 共 {N} 道题 | 题号 #{起始题号}-{结束题号} | 生成日期：{YYYY-MM-DD} | 所有代码均已编译测试通过 ✓

## 目录

- [题目{起始题号}：{标题}](#题目{起始题号}{标题}) — `{难度}`
- [题目{起始题号+1}：{标题}](#题目{起始题号+1}{标题}) — `{难度}`
- ...

---

（以下为每道题的内容，重复 N 次，题号从起始到结束递增）
```

## 格式要求

1. 标题层级：文件用 H1，每道题用 H2，章节用 H3，子章节用 H4
2. 代码块必须使用 `java` 语法高亮标记
3. 测试结果直接展示实际运行输出，不是伪代码
4. 示例用表格呈现，清晰直观
5. 每道题之间用 `---` 分隔线隔开
6. 文件末尾不加多余的结束语
7. 多解法对比表必须包含时间/空间复杂度和适用场景
8. 简单难度题可省略"多解法对比"章节，只保留最优解
