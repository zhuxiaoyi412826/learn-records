以下是「出题专家」插件套件完整的 Skill 和文件知识库导出：

## 插件整体结构



```
coding-problem-generator/
├── plugin.json
├── skills/
│   ├── 编程出题/
│   │   ├── SKILL.md                        ← 核心出题技能
│   │   └── references/
│   │       ├── json-template.md             ← JSON 输出模板
│   │       └── problem-template.md          ← Markdown 输出模板
│   └── 题库知识/
│       ├── SKILL.md                        ← 内部知识库（不可直接调用）
│       └── references/
│           ├── dsa-categories.md            ← 数据结构与算法分类
│           └── book-reference.md            ← 4本书籍 600+ 题目索引
```

共 **6 个文件**，下面逐一展示完整内容。

## 1. 编程出题/SKILL.md

这是核心技能定义，包含输入解析、难度标准、出题范围（10大类）、去重规则、全局题号机制（problem_history.json）、文件分卷规则（每100题一卷）、出题五步流程（构思→编码→编译验证→输出→更新记录）、代码规范和输出格式要求。

**关键要点：**

- 输入参数：主题、难度（简单/中等/困难）、数量（1-10）、输出格式（md/json/both）
- 全局题号从 D:\文件\算法\problem_history.json 的 lastId 递增
- 文件分卷：ID 1-100 → 算法题目.md/json，101-200 → 算法题目100-200.md/json，以此类推
- 每道题必须经过 javac 编译 + 测试验证，全部通过才输出
- 中等及以上必须多解法（至少2种），交叉验证
- 总结章节严格五步结构：题目概述→解题方法→时间复杂度→空间复杂度→改进方向

## 2. 编程出题/references/json-template.md

JSON 输出的完整 Schema 定义。文件顶层为 { version, generatedAt, totalProblems, problemRange, problems }，每道题包含 id/title/difficulty/category/problem/solutions/comparison/testCases/testResult/summary。

**关键规则：**

- 代码字段是含 \n 转义的字符串
- 简单题 comparison 为 null，中/困难必填（含 table/performanceNote/interviewTip）
- testResult.crossVerified 标记多解法交叉验证
- summary 严格五步结构，各步用 \n\n 分隔，整体 300-500 字

## 3. 编程出题/references/problem-template.md

Markdown 输出的格式模板。每道题 7 个章节：标题（含难度+类别标签）→ 题目 → 分析 → Java 代码 → 多解法对比 → 测试用例 → 总结。

**关键规则：**

- H1 文件标题 + H2 每道题 + H3 章节 + H4 子章节
- 代码块用 java 语法高亮
- 测试结果展示实际运行输出（[PASS]/[FAIL]）
- 示例用表格呈现
- 题间用 --- 分隔

## 4. 题库知识/SKILL.md

内部知识库技能（user-invocable: false），由「编程出题」技能在构思题目时自动引用。包含分类索引，指向 dsa-categories.md 和 book-reference.md。

## 5. 题库知识/references/dsa-categories.md

数据结构与算法的完整分类框架，包含：

- **数据结构**：线性结构（数组/链表/栈/队列）、树形结构（二叉树/BST/Trie/堆/线段树/BIT/ST表/跳表/平衡树）、图结构（BFS/DFS/最短路/MST/拓扑排序/二分图/Tarjan/欧拉路径）、高级结构（哈希表/并查集）
- **算法**：排序与搜索、动态规划（一维/二维/背包/字符串/区间/状态机/树形）、贪心、回溯与分治、字符串算法、数学与位运算、设计类
- **难度映射表**：每个类别按简单/中等/困难列出经典题目
- **5种常见出题模式**：直接求解、变体经典题、多步骤组合、设计类、实际场景

整合 4 本经典算法书籍的 600+ 题目索引，按 19 大类组织：

| 编号 | 书名                        | 语言 | 题数 |
| :--- | :-------------------------- | :--- | :--- |

**19 大分类**：数组、字符串、链表、栈与队列、二叉树、动态规划（4个子类）、贪心、回溯、二分查找、DFS/BFS、位运算、哈希表、排序、数学、图论、并查集、滑动窗口、高级数据结构（Trie/线段树/设计类）、分治

每道题标注了 LeetCode 编号、题目名、难度、来源书籍（ABCD）、关键解法。
