# 查找算法（Search / Lookup）

顺序查找、二分查找、插值查找、斐波那契查找、树表查找、哈希查找





- **核心目标**：**在固定、结构化数据集**中，精准定位**是否存在目标元素、元素位置 / 索引**。
- **前提**：数据集是**静态 / 预存储**的（数组、链表、哈希表、有序表、树）。
- **特点**：只查「有没有、在哪」，**不遍历复杂空间、不产生新路径 / 状态**。

**常见查找算法**

- 顺序查找（线性查找）
- 二分查找（折半查找，仅有序数组）
- 插值查找、斐波那契查找
- 哈希查找（散列查找）
- 二叉搜索树、平衡树（AVL / 红黑树）查找

## 线性查找

线性查找也称为顺序查找，是一种最简单的查找算法。在这种算法中，我们从数据集的开头开始，逐个比较每个数据项，以寻找要查找的数据。如果我们找到了目标数据，查找过程就结束了。如果我们到达数据集的末尾，仍然找不到目标数据，则可以认为它不存在于数据集中。

线性查找的时间复杂度是O(n)，其中n是数据集的大小。因此，它在大型数据集中可能会很慢。然而，在小型数据集中，它仍然是一种非常有用的算法。

## 二分查找

二分查找也称为折半查找，是一种更快速的查找算法。但前提是，数据集必须已经排序。在二分查找中，我们取数据集的中间值，然后将目标与中间值进行比较。如果目标小于中间值，则在左侧子集中继续查找；如果目标大于中间值，则在右侧子集中继续查找。每次比较都会缩小要搜索的数据集的大小。

二分查找的时间复杂度是O(log n)，其中n是数据集的大小。这种算法在大型数据集中非常有效，但在小型数据集中可能并不是最快的选择。

## 哈希表查找

哈希表查找也称为散列表查找，是另一种常见的查找算法。它利用哈希函数将数据项映射到散列表中的位置。在查找过程中，我们只需通过哈希函数计算目标数据的位置，然后检查该位置是否包含目标数据。

哈希表查找的时间复杂度是O(1)。这使得它成为大型数据集中最快的查找算法之一。但是，哈希表查找的效率取决于哈希函数的质量。如果两个数据项映射到相同的位置，就会发生哈希冲突，这可能会导致性能下降

## 对比

| 对比维度     | 查找算法                                 | 搜索算法                                  |
| ------------ | ---------------------------------------- | ----------------------------------------- |
| **作用范围** | 线性表、哈希、二叉搜索树等**结构化数据** | 图、树、迷宫、状态空间、解集空间          |
| **核心任务** | 查元素是否存在、下标、值                 | 找路径、最优解、可行方案、目标状态        |
| **数据特征** | 数据固定、结构简单                       | 状态多、分支多、空间复杂                  |
| **典型思想** | 顺序遍历、二分、哈希映射、树检索         | 遍历、回溯、贪心、广度 / 深度优先、剪枝   |
| **有无分支** | 无分支，单向查找                         | 多分支，需要选择 / 回退                   |
| **常见场景** | 通讯录查名字、数组找值、缓存命中         | 迷宫寻路、地图最短路径、AI 下棋、排列组合 |





## 一、无序序列查找

### 1. 顺序查找（线性查找）

- 适用：数组、链表，有序 / 无序均可
- 思路：从头逐个比对，找到即返回
- 复杂度：平均 O(n)，最好 O(1)，最坏 O(n)
- 缺点：数据量大时很慢

## 二、有序序列查找（前提：数组已升序 / 降序）

### 2. 二分查找（折半查找）

- 思路：每次取中间值，缩小一半查找区间
- 复杂度：O(logn)
- 变种：左边界二分、右边界二分、查找第一个 / 最后一个目标值

### 3. 插值查找

- 二分优化，按数值比例预估位置，适合均匀分布有序数组
- 理想复杂度 O(loglogn)，极端退化 O(n)

### 4. 斐波那契查找

- 用斐波那契分割区间，仅加减运算，无除法，适合硬件底层

## 三、树结构查找（适合频繁增删查）

### 5. 二叉搜索树 BST

左小右大，中序遍历有序；最坏退化成链表 O(n)

### 6. 平衡二叉树 AVL

左右子树高度差≤1，稳定 O(logn)

### 7. 红黑树

工程最常用平衡树（Java TreeMap/C++ map），O(logn)

### 8. B 树 / B + 树

多路平衡树，数据库、文件索引专用；

B + 树所有数据存在叶子，范围查找极强。

### 9. 字典树 Trie

专门处理字符串前缀查找（词频、自动补全）

## 四、哈希查找（平均最快）

### 10. 哈希表查找（散列查找）

通过哈希函数直接映射下标，不依赖有序

- 平均复杂度 O(1)，冲突最坏退化 O(n)
- 实现：Java HashMap、Python dict、C++ unordered_map
- 冲突解决：链地址法、开放寻址法

## 五、分块查找（索引顺序查找）

### 11. 分块查找

数组分块，建立索引表；先索引二分定位块，块内顺序查找

复杂度介于二分与线性之间，适合海量静态数据。

## 六、特殊字符串查找（文本检索类）

1. BF 暴力字符串匹配
2. KMP 匹配（预处理前缀表，跳过无效比对）
3. BM、Sunday 高速字符串查找
4. Rabin-Karp 哈希字符串匹配
