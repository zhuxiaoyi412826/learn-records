## 四、图 / 路径搜索（人工智能、迷宫、寻路、博弈）

### 无信息搜索（盲目搜索）

1. 广度优先搜索 BFS

   

   逐层遍历，能求出最短路径，队列实现。

2. 深度优先搜索 DFS

   

   一路走到底再回溯，栈 / 递归实现，不保证最短路径。

3. 一致代价搜索

   

   BFS 扩展，按路径代价从小到大拓展，求最小代价路径。

4. **深度受限搜索、迭代加深搜索**

### 有信息搜索（启发式搜索，带估价函数）

1. 贪心搜索

   

   只看当前最优，局部最优不一定全局最优。

2. *A* 搜索

   *

   

   最经典寻路算法（游戏地图、导航），高效找最优路径。

3. *IDA* 迭代加深 A

   **

   

   节省内存，适合大数据地图。

4. 双向 A * 搜索

   

   起点、终点同时向中间搜索，速度更快。

##  搜索算法（Search / Traverse）

- **核心目标**：在**复杂空间、状态空间、图 / 迷宫、解集空间**中，**寻找可行解、最优解、路径、目标状态**。
- **前提**：面对**未知、多分支、多状态**的复杂问题（迷宫、走棋、最短路径、组合问题）。
- **特点**：需要**状态遍历、分支选择、回溯、剪枝**，不止找元素，还要找方案。

常见搜索算法

1. 深度优先搜索 DFS
2. 广度优先搜索 BFS
3. 回溯搜索（组合、子集、全排列）
4. 发式搜索（A*、IDA*）
5. 最短路径搜索（Dijkstra、Floyd）
6. 暴力枚举、分支限界
7. 字符串匹配
