# java中排序算法

Java 并非只用一种排序，而是**混合排序（自适应排序）**，根据数据类型、数据长度自动切换算法。



**基本类型数组**：`Arrays.sort(基本类型数组)`

调用：`Arrays.sort(int[] a)`

底层算法：**双轴快速排序（Dual-Pivot QuickSort）**

### 

**对象数组 / List 集合**：`Arrays.sort(对象数组)`、`Collections.sort(List)`、`List.sort(Comparator)`

**TimSort** **归并排序 + 插入排序 的混合稳定排序**

Java 7 及以后统一使用 **TimSort**（源自 Python，现在也是主流工业级排序）。

| 调用方式                                 | 数据类型     | 底层算法               | 是否稳定 |
| ---------------------------------------- | ------------ | ---------------------- | -------- |
| `Arrays.sort(int[])`                     | 基本类型数组 | 双轴快排（小数组插排） | ❌ 不稳定 |
| `Arrays.sort(Object[])`                  | 对象数组     | TimSort                | ✅ 稳定   |
| `Collections.sort(List)` / `List.sort()` | 集合         | TimSort                | ✅ 稳定   |
