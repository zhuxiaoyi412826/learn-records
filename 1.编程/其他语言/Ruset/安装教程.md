## 正确完整操作（一步步照着来）

1. 先清理旧残留

```
Remove-Item -Recurse -Force C:\Users\Administrator\.rustup
Remove-Item -Recurse -Force C:\Users\Administrator\.cargo
```

1. 设置国内镜像

```
$env:RUSTUP_DIST_SERVER="https://mirrors.ustc.edu.cn/rust-static"
$env:RUSTUP_UPDATE_ROOT="https://mirrors.ustc.edu.cn/rust-static/rustup"
```

1. 启动安装程序

```
.\rustup-init.exe
```

1. 出现菜单：

```
1) Proceed with standard installation (default - just press enter)
2) Customize installation
3) Cancel installation
>
```

👉 **这里输入 `2` 回车**（进入自定义，不要直接输目标三元组！）

1. 接下来才会提问：

```
Default host triple? [x86_64-pc-windows-msvc]
>
```

👉 这里输入：`x86_64-pc-windows-gnu` 回车



```
Default toolchain? (stable/beta/nightly/none) [stable]
>
```

👉 **直接回车**



```
Profile (which tools and data to install)? (minimal/default/complete) [default]
>
```

👉 **这里输入 `minimal` 回车**（这一步才是设置最小化）



```
Modify PATH variable? (Y/n)
>
```

👉 输入 `Y` 回车

1. 回到最初菜单，输入 `1` 回车，开始安装。
2. 后面弹出：`Continue? (y/N)`，输入 `y` 回车。

------

### 重点区分

- 第 4 步的菜单：只能输入 `1 / 2 / 3`，**不能直接写 `x86_64-pc-windows-gnu`**，否则直接终止安装。
- 只有进入 `Customize installation`（选 2）之后，才可以填写 host triple、profile。

### 安装完成

全部跑完，**关闭全部 PowerShell 窗口，新开一个终端**

```
rustc --version
cargo --version
```

```
Remove-Item -Recurse -Force C:\Users\Administrator\.rustup -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force C:\Users\Administrator\.cargo -ErrorAction SilentlyContinue
$env:RUSTUP_DIST_SERVER="https://mirrors.ustc.edu.cn/rust-static"
$env:RUSTUP_UPDATE_ROOT="https://mirrors.ustc.edu.cn/rust-static/rustup"
.\rustup-init.exe --default-host x86_64-pc-windows-gnu --default-toolchain stable --profile minimal
```

## demo案例

完整代码

```
fn main() {
    // 设置要输出的行数
    let n = 10;
    let triangle = generate_yanghui(n);

    // 格式化居中打印
    let total_width = n * 2;
    for row in triangle {
        let line: Vec<String> = row.iter().map(|num| num.to_string()).collect();
        println!("{:^width$}", line.join(" "), width = total_width);
    }
}

/// 生成n行杨辉三角
fn generate_yanghui(n: usize) -> Vec<Vec<u32>> {
    // 这里加上显式类型标注 Vec<Vec<u32>>
    let mut result: Vec<Vec<u32>> = Vec::new();
    for i in 0..n {
        // 每行初始化全部为1
        let mut current_row = vec![1; i + 1];
        // 计算中间数字：上一行相邻两数相加
        for j in 1..i {
            current_row[j] = result[i - 1][j - 1] + result[i - 1][j];
        }
        result.push(current_row);
    }
    result
}

```
