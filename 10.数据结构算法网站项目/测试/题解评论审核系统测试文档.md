# 题解评论审核系统 - 测试文档

## 一、系统概述

### 1.1 功能简介

本系统为 Online Judge (OJ) 平台提供用户题解发布、评论互动和后台审核管理功能。用户可以发布题解、发表评论，管理员可以审核违规内容。

### 1.2 技术架构

| 层级 | 技术栈 |
|------|--------|
| 前端（用户端） | HTML + CSS + JavaScript (原生) |
| 前端（后台） | Vue 3 + TypeScript + Element Plus |
| 后端 | Spring Boot 3.2 + MyBatis |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis |
| 敏感词检测 | DFA 前缀树算法 |

### 1.3 模块结构

```
用户端 (qianduan/)
├── oj.html                    # 题目详情页（含题解列表）
└── js/oj-solution.js         # 题解相关前端逻辑

后台管理端 (houtai/)
└── src/views/audit/
    └── SolutionReview.vue     # 题解审核页面

后端 (houduan/)
├── controller/
│   ├── OJSolutionController.java           # 用户侧接口
│   └── OJSolutionAdminController.java      # 后台审核接口
├── service/
│   ├── OJSolutionService.java              # 题解业务逻辑
│   └── OJSolutionCommentService.java       # 评论业务逻辑
├── mapper/
│   ├── OJSolutionMapper.java
│   └── OJSolutionCommentMapper.java
└── audit/
    ├── AuditDetectService.java              # 敏感词检测
    ├── DfaTrie.java                         # DFA 前缀树
    └── SensitiveWordService.java           # 敏感词管理
```

## 六、审核流程说明

### 6.1 敏感词检测等级

| 等级 | 处理方式 | 审核状态 | 适用场景 |
|------|----------|----------|----------|
| HIGH | 直接拦截 | blocked | 色情、赌博、严重违法 |
| MEDIUM | 入库待审 | pending | 辱骂、广告、一般违规 |
| LOW | 入库记录 | logonly | 轻微风险，仅记录 |

### 6.2 审核状态流转

```
                    ┌──────────┐
                    │   none   │  ← 无命中敏感词
                    └────┬─────┘
                         │
                    ┌────▼─────┐
                    │  pending  │  ← MEDIUM 级命中，待审核
                    └────┬─────┘
                    ┌────┼────┐
                    │    │    │
              ┌─────▼┐  │  ┌──▼───┐
              │passed│  │  │reject│
              └──────┘  │  └──────┘
                    审核通过  审核驳回
                    
              ┌──────────┐
              │  blocked  │  ← HIGH 级命中，直接拦截
              └──────────┘
```

### 6.3 题库中的敏感词分类

| 分类 | 关键词示例 | 等级 |
|------|-----------|------|
| PORNOGRAPHY（色情） | 色情、裸聊、约炮 | HIGH |
| GAMBLING（赌博） | 赌博、博彩、下注 | HIGH |
| ABUSE（辱骂） | 傻逼、草泥马、废物 | MEDIUM |
| ADVERTISING（广告） | 办证、代开发票、刷单 | MEDIUM |
| OTHER（其他） | 外挂、刷分、黑产 | MEDIUM/LOW |

## 七、常见问题与排查

### 7.1 题解审核页面无数据

| 可能原因 | 排查步骤 |
|----------|----------|
| 后端未重启 | 重新编译并重启 Spring Boot |
| 前端缓存 | 清除 Vite 缓存或重启前端服务 |
| 接口路径错误 | 检查浏览器 Network 面板，确认请求 `/api/admin/solutions` 返回正确 |
| 数据库无数据 | 确认 `oj_solution` 表中有记录 |

### 7.2 敏感词未生效

| 可能原因 | 排查步骤 |
|----------|----------|
| 敏感词库未更新 | 执行 SQL 脚本 `update_sensitive_words.sql` |
| 缓存未刷新 | 调用 `POST /api/audit/words/refresh-cache` |
| 服务未重启 | 重启后端服务重新加载 DFA 树 |

### 7.3 接口 401 错误

| 可能原因 | 排查步骤 |
|----------|----------|
| 未登录 | 添加 `X-User-Id` 请求头 |
| Token 过期 | 重新登录获取 Token |
| 路径被拦截 | 检查 `AuthInterceptor` 排除配置 |

## 八、功能不足与后续扩展

### 8.1 现有不足

| 序号 | 不足项 | 说明 |
|------|--------|------|
| 1 | 无前端富文本审核 | 后台只能查看纯文本，无法预览富文本格式 |
| 2 | 无批量审核 | 管理员需要逐条审核，效率较低 |
| 3 | 无审核统计报表 | 缺少审核量统计、违规率分析等数据 |
| 4 | 无敏感词热更新 | 新增敏感词需重启服务才能生效 |
| 5 | 评论无举报功能 | 用户无法举报违规评论 |
| 6 | 无审核记录日志 | 审核操作无历史记录，无法追溯 |
| 7 | 缺乏自动审核规则 | 完全依赖人工审核，无机器学习辅助 |

```
- target_id: 目标ID
- action: pass/reject/block
- reason: 操作原因
- created_at: 操作时间

功能：
1. 管理员操作留痕
2. 支持操作回滚（限审核通过后可撤回）
3. 导出审核日志报表
```
