## ❌ 失败用例分类汇总

### 第一类：用户登录接口 HTTP 500（3 + 1 = 4 个用例）
**根因**: `POST /api/login` 接口内部异常，测试脚本与后端实际接口不匹配。

| # | 测试类::测试方法 | HTTP 响应 | 说明 |
|---|-----------------|-----------|------|
| 1 | `TestAuth::test_login_success` | HTTP **500** | 用户正常登录失败 |
| 2 | `TestAuth::test_login_wrong_password` | HTTP **500** | 错误密码登录接口500 |
| 3 | `TestAuth::test_login_nonexistent_user` | HTTP **500** | 不存在用户登录接口500 |
| 4 | `TestSecurity::test_sql_injection_login` | HTTP **500** | 同上，因登录接口本身500 |

#### 🔍 后端实际情况调查
- **Controller 位置**: `LoginController.java` → `@RequestMapping("/api/login")`
- **公开方法 1**: `POST /api/login`（`@PostMapping` 无路径后缀） → 摘要："通过验证码登录"
- **公开方法 2**: `POST /api/login/account`（`@PostMapping("/account")`） → 摘要："账号密码登录"
- **登录鉴权方式**: Session + Cookie（非 Bearer Token！）
- **WebConfig 排除路径**: 已排除 `/api/login`、`/api/login/account`

#### 🐛 问题分析
1. **调用方法错**: 脚本调用 `POST /api/login`，该接口用途为 **验证码登录**，参数为 `code`，而非 `{username, password}`
   - 正确的账号密码登录路径应为：`POST /api/login/account`
2. **返回类型错**: 脚本期待 JSON 体里有 `token` 字段，但该后端账号登录使用 **Cookie + Session**，JWT token 根本不返回，返回的是 `LoginResponse` 对象且通过 `Set-Cookie` 写会话。
3. **HTTP 500 的直接原因**: `loginService.login(LoginRequest)` 的实现里需要 `code` 字段，脚本传 `username/password` 导致空指针或参数缺失 → 抛出异常。

#### ✅ 修复建议（明天改脚本）
- 账号密码登录改用 `POST /api/login/account`
- 使用 `requests` 库的 `session` 对象保持 Cookie，不要用 Bearer Token 鉴权
- 普通用户认证方式：**请求时携带 JSESSIONID Cookie**，不要在 `Authorization: Bearer xxx` header 传值

### 第五类：题解审核列表返回结构为空 → KeyError: 0（2 个用例）
**根因**: `sol_list = data.get("list", data.get("data", []))` 如果 InterviewResponse 包装结构不是 `data.data.list` 或 `data.list`，或者为空集合为 `Map` 不是数组，就会返回空 dict `{}` 而非空 list，然后 `sol_list[0]` 触发 KeyError。

| # | 测试类::测试方法 | 异常 | 说明 |
|---|-----------------|------|------|
| 24 | `TestAudit::test_audit_pass_solution` | `KeyError: 0` | `sol_list` 不是 list 是 dict/空对象 |
| 25 | `TestAudit::test_audit_reject_solution` | `KeyError: 0` | 同上 |

#### 🔍 实际返回结构
根据 OJSolutionAdminController.java#L30：
```java
public InterviewResponse<PageResult<OJSolution>> list(...) {
    PageResult<OJSolution> r = solutionService.adminList(...);
    return InterviewResponse.ok(r);
}
```
InterviewResponse.ok(r) 返回 `{code:200, message:"ok", data: {list:[...], total:N, page:1, ...}}`。

脚本当前取列表：
```python
sol_list = data.get("list", data.get("data", []))
```
❌ 问题：当 data = `{code:200, message:"ok", data:{list:[...]}}` 时  
- `data.get("list")` → 外层没有 list 字段，返回 None  
- `data.get("data", [])` → `{list: [...], total: N}` 是 dict  
- 最终 sol_list = `{list:[...]}`（dict！）  
- `sol_list[0]` → KeyError

#### ✅ 修复建议（明天改脚本）
```python
def _extract_list(resp_json):
    # 兼容 InterviewResponse / ApiResponse / Map 返回
    if isinstance(resp_json, dict):
        # InterviewResponse: {code, msg, data: PageResult{list,total,page...}}
        inner = resp_json.get("data")
        if isinstance(inner, dict):
            if isinstance(inner.get("list"), list):
                return inner["list"]
        # Map 直接返回
        if isinstance(resp_json.get("list"), list):
            return resp_json["list"]
        if isinstance(resp_json.get("problems"), list):
            return resp_json["problems"]
    return []
```
另外判断空时用：`if not sol_list: pytest.skip("无待审核题解")` 然后 `sol_id = sol_list[0].get("id")`
