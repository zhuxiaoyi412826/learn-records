# 前台用户功能

## 1. 用户中心模块

1. **登录注册**
   - 账号密码、手机号/邮箱验证码、第三方（企业 SSO/LDAP/OAuth）登录、SSO单点登录
   - 个人信息：昵称、头像、岗位、部门、求职意向、编程语言偏好
   - 修改密码、 邮箱/短信验证码找回
2. **个人主页**
   - 刷题总览：总题量、AC 数、通过率、提交次数、总耗时、打卡天数
   - 个人题解、提交记录公开 / 私有设置
   - 个人刷题统计图表：日 / 周 / 月刷题量，难度分布，语言分布
3. **我的收藏**：收藏题目、收藏题解
4. **错题本**：做错题目汇总，按错误类型筛选，一键重新刷题
5. **我的笔记**：针对每道题写笔记，支持 markdown，私有 / 公开
6. **账号设置**：主题切换（深色 / 浅色）、代码编辑器配置、默认语言、代码字体字号
7. 我的提交记录  历史提交、状态筛

## 2. 题库模块（核心）

1. 题目列表页

   - 分页、搜索：题目名称、ID、标签搜索
   - 多维度筛选：难度（简单 / 中等 / 困难）、标签（数组、DP、二叉树、SQL、Java、Go 等）、专题分类、岗位专项（后端、测试、算法、前端）
   - 题目卡片展示：题号、标题、难度、通过率、AC 状态、标签
   - 排序：通过率、热度、题目 ID、最近更新

2. 题目详情页

   - 题干展示：描述、输入输出样例、数据范围、提示、图片
   - 多语言切换题目（可选）
   - 标签、所属专题、参考用时

3. 标签体系

   算法标签（动态规划、图论等）、企业标签、热度

4. 代码编辑器（OJ 核心交互）

   - 多编程语言切换：Java、Python、Go、C++、JS、SQL 等
   - 语法高亮、行号、自动缩进、代码补全
   - 代码模板：每个语言内置默认模板代码
   - 自定义代码片段保存
   - **自测用例**：自定义输入，本地运行看输出（不提交判题）
   - **提交代码**，发送到判题机
   - 提交结果弹窗：AC / WA / TLE / MLE / RE / CE，显示错误样例，输出信息
   - 历史提交记录列表：每一次提交的代码、得分、运行时间、内存消耗

5. 题解模块

   - 官方题解、用户公开题解
   - 题解点赞、收藏、评论
   - 用户可以发布自己的题解
   - 官方题解、算法提示、来源标注（支持隐藏答案模式）

6. 分类专题

   按专题/知识图谱组织，如 LeetCode 式题单

## 3. 练习模式

1. **专题练习**：按专题刷题（动态规划、链表、数据库等）
2. **专项岗位题库**：后端专项、测试专项、大数据专项
3. **闯关模式**：按关卡顺序做题，完成一关解锁下一关
4. **随机刷题**：按难度 / 标签随机抽题
5. **周打卡 / 学习计划**：企业下发学习任务，每日任务清单

## 4. 做题在线提交

| 功能         | 说明                                                      |
| :----------- | :-------------------------------------------------------- |
| 在线编辑器   | 多语言支持（C/C++/Java/Python/Go 等）、代码高亮、自动补全 |
| 代码提交     | 提交、运行（Run）、提交评测（Submit）                     |
| 实时判题结果 | Accepted / Wrong Answer / TLE / MLE / RE / CE 等状态展示  |
| 编译错误详情 | 展示编译器错误信息、错误行定位                            |
| 样例自测     | 自定义输入运行单个测试用例                                |
| 草稿保存     | 云端保存未提交代码                                        |
| 调试辅助     | 断点/输出调试信息（可选，视企业需求）                     |

## 5. 竞赛模块（可选）

| 功能         | 说明                                        |
| :----------- | :------------------------------------------ |
| 比赛列表     | 进行中、即将开始、已结束                    |
| 报名参赛     | 报名、密码赛（私密赛）、团队赛              |
| 排名看板     | 实时榜单（Ranklist）、封榜机制              |
| 赛题提交     | 比赛内独立评测、罚时计算（ACM 制 / IOI 制） |
| 个人训练模式 | 模拟赛、限时训练、错题重练                  |
| 成绩单/证书  | 赛后成绩、排名、电子证书                    |

## 6. 排行榜 & 统计

1. **全局排行榜**：AC 数量、总得分、近 7 天刷题排行
2. **部门排行榜**（企业特色）：按部门维度排行，只看本企业内部人员
3. 个人统计大盘
   - 按标签统计：哪些知识点正确率低
   - 提交统计：WA/TLE 错误占比
   - 刷题日历打卡视图

## 7. 讨论社区（可选）

- 题目评论区：针对本题提问讨论
- 提问发帖，回复点赞
- 可以关闭社区（企业内网 OJ 常关闭，只允许刷题）

## 8. 消息通知

- 系统消息：考试提醒、任务通知
- 题解评论回复通知
- 站内信

## 9. 权限隔离（企业特有）

- 用户只能看到分配给自己的题库、考试
- 外部公开题目 + 企业私有题目混合
- 部分考试仅指定部门可见

## 10. 其他辅助功能

1. 导出：导出自己提交代码、导出错题
2. 草稿保存：代码自动保存，刷新页面不丢失
3. 帮助文档：判题状态说明、输入输出说明
4. 移动端适配：手机简单刷题看题

1. SSO 企业账号登录，对接企业内部组织架构
2. 部门排行榜、企业私有题库、岗位定向题库
3. 企业内部考试，权限管控，限制谁可以参加考试
4. 学习任务，管理员下发刷题任务，用户看任务清单
5. 考试防作弊相关提示（切屏检测、禁止复制）
6. 没有公开社区，大多对内，不对外暴露

# 后台管理功能

> 面向在线判题系统，包含：系统权限、用户管理、题目题库管理、比赛管理、提交判题管理、测评机管理、内容公告、数据统计大盘、系统配置、审计日志。 适配业务：学生刷题、算法竞赛、校园 OJ，对接判题服务、Judge 判题机集群。

# OJ 在线评测系统‑管理后台详细功能

> 面向在线判题系统，包含：系统权限、用户管理、题目题库管理、比赛管理、提交判题管理、测评机管理、内容公告、数据统计大盘、系统配置、审计日志。 适配业务：学生刷题、算法竞赛、校园 OJ，对接判题服务、Judge 判题机集群。

## 1. 权限账号模块（RBAC）

### 1.1 后台管理员账号

- 管理员列表：账号、姓名、角色、邮箱、手机号、状态、最后登录时间
- 操作：新增、编辑、启用 / 禁用、重置密码
- 个人中心：修改密码、个人资料

### 1.2 角色管理

预置角色：超级管理员、题库管理员、竞赛管理员、普通运营、只读审计

- 角色新增编辑，分配菜单权限、按钮权限、接口权限
- 权限粒度：题目增删改、比赛创建、数据导出、判题机配置

### 1.3 安全策略

- 登录失败锁定、密码复杂度策略
- IP 白名单，限制后台访问来源
- 操作审计日志（所有管理员操作留痕不可删除）

## 2. OJ 用户管理（C 端刷题用户）

管理所有参赛 / 刷题学生账号

1. 用户列表
   - 字段：用户 ID、用户名、昵称、邮箱、学号、学院班级、注册时间、总 AC 数、总提交数、状态
   - 筛选：学号、用户名、时间范围、账号状态；支持导出
2. 用户详情页
   - 用户基础信息、提交记录、AC 题目列表、参与过的比赛、个人签名
3. 账号操作
   - 启用 / 封禁账号（作弊用户封禁）、重置密码、修改个人信息
   - 用户标签：标记作弊、VIP、新生等标签
4. 用户批量操作
   - 批量导入账号（校园 OJ 批量导入学生学号）、批量导出用户

## 3. 题库题目管理（OJ 核心模块）

### 3.1 题目列表

字段：题目 ID、标题、难度、时间限制、内存限制、AC 数、提交数、通过率、状态、标签 筛选：难度、标签、状态、是否公开 状态：草稿、公开、私有、比赛专用（仅比赛内可见）

### 3.2 题目编辑

- 基础信息：标题、题目编号、难度、时间限制 (ms)、内存限制 (MB)、是否 SPJ 特殊判题、是否公开
- 题目内容：题干、输入描述、输出描述、样例输入输出、提示（Markdown 富文本编辑器，支持 LaTeX 数学公式）
- 标签管理：算法标签（DFS、DP、二分）、难度标签
- 测试用例管理
  - 上传 in 输入文件、out 输出答案文件
  - 批量上传测试用例、单条增删测试点
  - 设置每个测试点分值、时间 / 内存单独限制
- SPJ 特殊判题配置：上传 spj 判题程序
- 题目附件：题目素材、下载文件
- 预览：预览题目学生端页面效果

### 3.3 题目分类 & 标签库

- 分类管理：题库分类（入门、提高、竞赛真题）
- 算法标签维护，统一管理标签库

### 3.4 题目批量管理

- 批量导入题目（导入 OJ 标准数据包）、批量导出题目
- 批量修改状态、难度、标签

### 3.5 题目版本管理

- 题目修改历史记录，可回滚历史版本；记录修改管理员

## 4. 比赛 / 竞赛管理

### 4.1 比赛列表

字段：比赛 ID、比赛名称、开始时间、结束时间、报名截止、比赛状态、参赛人数、公开状态 状态：未开始、进行中、已结束

### 4.2 比赛创建 & 编辑

- 基础信息：比赛名称、简介、开始 / 结束时间、报名模式
- 报名模式：公开报名、密码参赛、白名单参赛（指定学号 / 用户才能参加）
- 比赛权限：公开比赛 / 私有内部比赛
- 排行榜配置：是否实时榜单、是否封榜时间、榜单显示规则
- 选择本场比赛题目：从题库挑选题目，设置每题分值

### 4.3 参赛人员管理

- 参赛名单列表
- 白名单导入导出；手动添加参赛选手；移除选手
- 查看选手提交记录

### 4.4 比赛榜单管理

- 实时排行榜查看
- 封榜控制：手动开启 / 关闭封榜
- 导出最终比赛榜单（成绩、排名、AC 情况，用于评奖）

### 4.5 比赛回放与数据

- 比赛提交总览，赛后可查看所有提交记录

## 5. 提交记录 & 判题管理

> 对接 Judge 判题集群，管理所有用户代码提交

### 5.1 全局提交列表

每条提交记录：提交 ID、用户、题目、语言、提交时间、判题结果、用时、内存、代码预览 判题结果：AC 正确、WA 答案错误、TLE 超时、MLE 内存超限、RE 运行错误、CE 编译错误

- 筛选：用户、题目、判题结果、语言、时间范围
- 查看源代码：预览用户提交代码
- 查看判题详情：每个测试点得分、运行时间、内存、错误信息

### 5.2 异常提交处理

- 重判功能：**单条重判、整题批量重判、比赛全部提交重判**（修改测试数据后必须重跑）
- 取消提交记录（作弊标记）

### 5.3 作弊检测模块（OJ 高频需求）

- 代码相似度检测：对提交代码查重，输出相似度报告，标记疑似抄袭提交
- 作弊标记：标记用户 / 提交为作弊，计入用户档案

## 6. 测评机 (Judge) 集群管理

> OJ 特有后台，管理判题工作节点

1. 判题机节点列表
   - 节点名称、IP、状态（在线 / 离线）、当前任务数、队列积压数量、CPU / 内存负载
2. 队列监控
   - 待判题队列长度，排队任务统计
3. 节点操作
   - 启用 / 禁用判题节点；查看节点运行日志
4. 全局判题配置
   - 全局默认时间、内存限制；支持语言配置（C/C++/Java/Python 编译参数）
   - 判题安全沙箱参数配置

## 7. 公告 & 站内消息

1. 公告管理
   - 公告列表、新增编辑公告、置顶、发布 / 下线；设置生效时间
2. 站内消息
   - 给用户批量发送站内通知；消息模板管理
   - 消息发送记录

## 8. 数据大盘与统计分析

### 8.1 全局统计面板

- 总用户数、总题目数、总提交量、AC 数量
- 日提交趋势图、每日新增用户
- 判题队列积压监控、判题机负载概览

### 8.2 题库统计

- 题目通过率排行，高 WA 错题统计，分析难点题目

### 8.3 用户统计

- 用户刷题统计，活跃度统计

### 8.4 比赛统计

- 每场比赛参赛数据，得分分布

## 9. 系统配置

1. 站点配置：OJ 网站名称、页脚、注册开关、是否开放注册
2. 全局参数配置
   - 默认时间内存限制、代码最大长度、提交频率限流（防止恶意大量提交压垮判题机）
   - 查重相似度阈值配置
3. 字典管理：语言列表、判题结果字典
4. 文件存储配置：题目附件、用户代码存储路径

## 10. 日志审计

1. 管理员操作日志：谁，何时，做了什么操作，修改前后数据，不可删除
2. 用户登录日志
3. 判题系统日志：判题任务异常日志，排查判题机故障
4. 系统错误日志

## 11. 可选高级功能

1. 训练集 / 专题训练管理：专题套题，批量题目组成训练单元
2. 证书生成：比赛结束批量生成电子证书
3. 导出报表：学生成绩报表，对接教务系统
4. 缓存管理：后台刷新题库缓存
5. 举报管理：用户举报题目、举报抄袭，后台审核处理

## OJ 后台开发重点踩坑

1. **重判是高危操作**：批量重判会大量打满判题机队列，后台要做限流，防止压垮 Judge 集群；重判操作记入审计日志
2. 代码、测试用例文件量大，做好存储规划；不要全部放数据库
3. 后台不能直接操作判题机，通过消息队列下发判题任务
4. 导出榜单、大量提交记录导出，做异步导出，避免大查询拖垮数据库
5. SPJ 特殊判题程序上传，做好沙箱隔离，防止恶意代码
