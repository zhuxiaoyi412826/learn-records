# 数据结构

### 一、线性数据结构

| 数据结构                | 说明                                                         |
| ----------------------- | ------------------------------------------------------------ |
| **数组（Array）**       | 连续存储的同类型元素序列，通过下标常量时间访问               |
| **链表（Linked List）** | 由节点组成的序列，每个节点包含数据和一个或多个指针，支持动态扩展 |
| **栈（Stack）**         | 后进先出（LIFO）结构，插入和删除只能在栈顶进行               |
| **队列（Queue）**       | 先进先出（FIFO）结构，一端插入、另一端删除                   |
| **双端队列（Deque）**   | 两端均可插入和删除的队列                                     |
| **字符串（String）**    | 字符序列，支持长度计算、字典序比较、连接等操作               |

### 二、树形结构

| 数据结构                      | 说明                                                         |
| ----------------------------- | ------------------------------------------------------------ |
| **树（Tree）**                | 分层存储元素，每个节点有双亲和孩子，根节点为顶层             |
| **二叉树（Binary Tree）**     | 每个节点最多有两个孩子                                       |
| **二叉搜索树（BST）**         | 左子树所有节点小于根，右子树所有节点大于根，支持 O(log N) 平均时间搜索 |
| **AVL 树**                    | 自平衡二叉搜索树，通过单旋转/双旋转保持平衡                  |
| **红黑树（Red-Black Tree）**  | 带颜色约束的平衡二叉搜索树，常用于函数式数据结构             |
| **伸展树（Splay Tree）**      | 通过"展开"操作将访问过的节点移到根                           |
| **B-树**                      | 多路搜索树，适合磁盘存储                                     |
| **Trie（字典树/数字搜索树）** | 适用于字符串等聚合类型键的搜索                               |

### 三、堆与优先队列

## 一、算法的主要分类体系

根据《算法设计与分析基础》第3版，算法最主要的两种分类方式是：

1. **按求解问题的类型分组**（排序、查找、字符串处理、图问题、组合问题、几何问题、数值问题）
2. 按内在的设计技术/策略/范式分组

# 核心

## 第一梯队：面试+竞赛双必考（最高优先级）

这些是无论面试还是竞赛都绕不开的，必须做到手写无误：

- **数组、哈希表** — 最基础的数据结构，几乎所有题的底层
- **二叉树遍历、BFS、DFS** — 树和图的搜索是面试高频中的高频
- **二分查找** — 看似简单，边界条件是真正的考点
- **快排、归并** — 手写排序是面试经典题
- **动态规划** — 面试的"分水岭"，竞赛的基础工具
- **回溯** — 全排列、组合、N皇后，面试必考

## 第二梯队：面试必考

- **链表** — 反转、合并、环检测，面试超高频
- **双指针、滑动窗口** — 面试中的"套路题"核心技巧
- **堆/优先队列** — Top-K 问题的标配
- **分治** — 归并排序的思想延伸

## 第三梯队：竞赛必考（面试加分项）

- **线段树、树状数组** — 区间操作的利器
- **字典树 Trie** — 字符串前缀问题
- **并查集** — 连通性问题首选
- **单调栈/队列** — 求下一个更大/更小元素
- **最短路径、最小生成树、拓扑排序** — 图论三件套
- **前缀和/差分** — 区间求和的快捷方式

------

## 建议的学习路线

1. **先打地基**：数组 → 链表 → 栈/队列 → 哈希表 → 二叉树
2. **再学搜索**：二分查找 → DFS → BFS → 回溯
3. **然后排序**：快排 → 归并 → 堆排
4. **进阶思想**：贪心 → 动态规划（最花时间，也最值得）
5. **竞赛拔高**：线段树 → 并查集 → 图论算法 → 单调栈/队列
