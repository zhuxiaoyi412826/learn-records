| 日志类型                | 命名模板                   | 示例                                  | 备注                                 |
| ----------------------- | -------------------------- | ------------------------------------- | ------------------------------------ |
| JVM GC 日志             | `{app}-gc.log`             | `oj-backend-gc.log`                   | JVM 自动轮转，后缀`.log.0/.log.1`    |
| JVM 崩溃 hs_err         | `hs_err_{app}_%p.log`      | `hs_err_oj-backend_12440.log`         | `%p`JVM 自动替换 PID，**必须带 % p** |
| OOM 堆 dump hprof       | `{app}-%p-%t.hprof`        | `oj-backend‑12440‑202608201830.hprof` | 二进制，不采集 EFKS，`%t`时间戳      |
| SpringBoot 业务全量日志 | `{app}.log`                | `oj-backend.log`                      | logback 按日期滚动                   |
| SpringBoot error 日志   | `{app}-error.log`          | `oj-backend-error.log`                | 只存 ERROR 级别堆栈                  |
| MySQL 错误日志          | `mysql-error.log`          | `mysql-error.log`                     | logrotate 做系统层滚动               |
| MySQL 慢查询            | `mysql-slow.log`           | `mysql-slow.log`                      | logrotate 滚动                       |
| Redis 日志              | `redis-server.log`         | `redis-server.log`                    | logrotate 滚动                       |
| ES 系统日志             | `elasticsearch.log`        | `elasticsearch.log`                   | ES 内置 log4j2 滚动                  |
| ES 慢查询               | `index_search_slowlog.log` | `index_search_slowlog.log`            | ES 内置滚动                          |
