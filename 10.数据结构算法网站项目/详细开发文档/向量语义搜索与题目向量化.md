**用户操作**：在前台面试题库页面输入搜索词（如"动态规划"），点击 "AI 搜索" 按钮。

### 2.1 流程总览

```
步骤 1: 前端 → Spring Boot  (GET /api/vector/search?query=xxx&topK=30)

步骤 7: Spring Boot: 按相似度顺序排列题目 → 返回给前端
步骤 8: 前端: 渲染题目列表
```

```java
public InterviewResponse<List<InterviewProblem>> semanticSearch(String query, int topK) {
    try {
        // ① 向量召回：通过 Feign 调用 Python 服务
        VectorSearchRequest searchReq = new VectorSearchRequest();
        searchReq.setQuery(query);
        searchReq.setTopK(topK);
        VectorSearchResponse searchResp = vectorClient.search(searchReq);

        if (searchResp == null || searchResp.getResults() == null
                               || searchResp.getResults().isEmpty()) {
            return fallbackSearch(query);  // 降级 1：向量结果为空
        }

        // ② 提取 problemId 列表（按相似度降序排列）
        List<Long> ids = searchResp.getResults().stream()
                .map(VectorSearchResultItem::getProblemId)
                .filter(Objects::nonNull)
                .toList();

        if (ids.isEmpty()) return fallbackSearch(query);

        // ③ MySQL 查完整题目
        List<InterviewProblem> problems = problemMapper.selectByIds(ids);
        if (problems.isEmpty()) return fallbackSearch(query);

        // ④ 按向量返回顺序重排（MySQL IN 查询不保证顺序）
        Map<Long, InterviewProblem> idMap = problems.stream()
                .collect(Collectors.toMap(InterviewProblem::getId, p -> p, (a, b) -> a));
        List<InterviewProblem> ordered = new ArrayList<>();
        for (VectorSearchResultItem r : searchResp.getResults()) {
            InterviewProblem p = idMap.get(r.getProblemId());
            if (p != null) ordered.add(p);
        }

        return InterviewResponse.ok("语义搜索成功", ordered);
    } catch (Exception e) {
        // 降级 2：向量服务异常（超时/网络错误）→ MySQL LIKE 搜索
        log.warn("[语义搜索] 向量服务异常，降级到 MySQL: {}", e.getMessage());
        return fallbackSearch(query);
    }
}
```

```python
# L264-L330 混合检索：向量语义召回 + 关键词匹配加权排序
@app.post("/api/v1/search")
async def search(req: SearchRequest):
    # ① 向量召回 — 取 3 倍候选量以便后续重排
    candidate_k = max(req.top_k * 3, 30)  # topK=30 → 候选90条
    raw_results = vector_store.search_by_text(req.query, candidate_k)

    if not raw_results:
        return {"results": [], "total": 0, "query": req.query}

    # ② 关键词匹配加分（解析用户搜索词）
    query_lower = req.query.lower().strip()
    query_terms = [t for t in query_lower.replace(',', ' ')
                                    .replace('，', ' ').split() if len(t) >= 1]

    scored_results = []
    for r in raw_results:
        vec_sim = r["similarity"]
        meta = r.get("metadata", {})

        # 关键词加权（多字段不同权重）
        kw_boost = 0.0
        if query_terms:
            title = (meta.get("title") or "").lower()
            tags = (meta.get("tags") or "").lower()
            category = (meta.get("category") or "").lower()
            doc = (r.get("document") or "").lower()

            for term in query_terms:
                if term in title:    kw_boost += 0.15  # 标题命中权重最高
                if term in tags:     kw_boost += 0.10  # 标签命中
                if term in category: kw_boost += 0.08  # 分类命中
                if term in doc:      kw_boost += 0.05  # 正文命中

        # ③ 混合得分公式：向量相似度(70%) + 关键词加权(最高30%)
        hybrid_score = min(1.0, vec_sim * 0.7 + min(kw_boost, 0.3) * 1.0)

        # ④ 阈值过滤（默认 threshold=0.3）
        if hybrid_score < req.threshold:
            continue

        scored_results.append({
            "problemId": int(meta.get("problem_id", 0)),
            "title": meta.get("title", ""),
            "similarity": round(hybrid_score, 4),
            "vecSimilarity": round(vec_sim, 4),  # 纯向量相似度，用于调试
            "kwBoost": round(kw_boost, 4),        # 关键词加分数，用于调试
            # ... 其他字段
        })

    # ⑤ 按混合得分降序排列
    scored_results.sort(key=lambda x: x["similarity"], reverse=True)

    # ⑥ 截取 top_k
    scored_results = scored_results[:req.top_k]

    return {"results": scored_results, "total": len(scored_results), "query": req.query}
```

**混合检索评分公式（核心）**：

```
混合得分 = clamp(vec_sim × 0.7 + min(kw_boost, 0.3), 0, 1)

其中：
  kw_boost = 标题命中数×0.15 + 标签命中数×0.10
           + 分类命中数×0.08 + 正文命中数×0.05
```

```java
// L62-L78 批量同步（导入时使用）
public void syncBatch(List<InterviewProblem> problems) {
    if (problems == null || problems.isEmpty()) return;
    try {
        List<VectorEmbedRequest> reqList = problems.stream()
                .filter(p -> p.getId() != null)
                .map(this::toEmbedRequest)
                .toList();
        VectorBatchEmbedRequest batchReq = new VectorBatchEmbedRequest();
        batchReq.setProblems(reqList);
        vectorClient.embedBatch(batchReq);    // 异步提交，立即返回
        log.info("[向量同步] 批量同步已提交: {} 条", reqList.size());
    } catch (Exception e) {
        log.warn("[向量同步] 批量同步失败: {} 条, err={}", problems.size(), e.getMessage());
    }
}
```

```python
def build_text(p: EmbedRequest) -> str:
    """构造向量化文本 — 尽可能丰富语义信息"""
    parts = []
    if p.title:
        parts.append(f"题目：{p.title}")
    if p.category:
        parts.append(f"分类：{p.category}")
    if p.tags:
        parts.append(f"标签：{p.tags}")
    if p.difficulty:
        parts.append(f"难度：{p.difficulty}")
    if p.description:
        desc = _strip_markdown(p.description)[:800]  # 去除 Markdown，前800字
        parts.append(f"描述：{desc}")
    if p.solution:
        sol = _strip_markdown(p.solution)[:500]      # ★ 题解前500字（关键）
        parts.append(f"题解：{sol}")
    return "\n".join(parts) if parts else (p.title or "")
```

```python
    return {"success": True, "message": f"已提交 {len(items)} 条题目到后台处理"}

def _do_batch_embed(items):
    """后台线程：实际执行批量向量化"""
    _sync_task_status["running"] = True
    try:
        result = vector_store.upsert_batch(items)    # 向量化 + ChromaDB upsert
        _sync_task_status["success"] = result["success"]
    finally:
        _sync_task_status["running"] = False

# L257-L260 同步任务状态查询接口（前端轮询显示进度）
@app.get("/api/v1/sync/status")
async def sync_status():
    return _sync_task_status
```

## 六、常见问题排查

| 现象                             | 可能原因                                       | 排查方法                                       |
| -------------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| 前台显示"语义搜索失败"JSON解析错 | 请求走了相对路径，返回 404 HTML                | 检查 `resolveApiBase()` 是否返回正确后端地址   |
| 搜索结果完全不相关               | ① 相似度公式错误 ② 向量未全量重建              | 确认 `1.0 - dist` 公式生效；重新全量同步向量库 |
| 全量同步报 30 秒超时             | 同步接口为异步，提交后后台执行，前端应轮询状态 | 检查 `/api/v1/sync/status` 是否完成            |
| 向量服务连接失败 500             | Python 服务未启动或端口不对                    | `curl http://localhost:8001/health` 验证       |
| 新导入题目搜不到                 | ① 未调用 syncBatch ② 向量服务离线              | 查看后端日志 `[向量同步] 批量同步已提交`       |
| 模型加载报 SSL 错误              | HuggingFace 在线下载被墙                       |                                                |
