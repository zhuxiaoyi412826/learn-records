# 企业级 Java 后端项目，标准服务器部署完整软件栈

> 说明：下面是**生产环境标准一套**，基于 Linux（主流 CentOS Stream / Ubuntu Server），物理服务器或者云服务器都适用。

## 一、系统层（基础操作系统）

- 操作系统：**Ubuntu Server 22.04 / CentOS Stream 9**（无图形界面，最小化安装）
- 必备系统工具：`vim`、`curl`、`wget`、`net-tools`、`htop`、`iostat`、`rsync`
- 安全层：防火墙 `firewalld/ufw`；fail2ban（暴力破解防护）；SSH 密钥登录（关闭密码登录）

| 工具      | 核心用途         | 后端 Java 排错场景                     |
| --------- | ---------------- | -------------------------------------- |
| vim       | 修改配置文件     | 改 yml、nginx、redis 配置              |
| curl      | http 接口调试    | 测试 SpringBoot 健康接口，排查接口不通 |
| wget      | 下载文件         | 下载 jdk、安装包、脚本                 |
| net‑tools | 网络端口查询     | netstat 看 8080、3306 端口是否监听     |
| htop      | CPU 内存进程监控 | 看 Java 进程内存占用，OOM 的时候定位   |
| iostat    | 磁盘 IO 性能     | 排查 MySQL 慢、磁盘读写瓶颈            |
| rsync     | 增量文件备份同步 | 备份数据库、日志、项目文件             |

------

## 二、Java 运行环境

1. JDK
   - OpenJDK / Amazon Corretto / Temurin（生产首选）
   - SpringBoot 项目直接内置 Tomcat，**不需要单独装 Tomcat**

> 只有老式 SSM 项目才单独部署 Tomcat 容器



------

## 三、反向代理 & 负载均衡（入口网关）

- **Nginx**（最常用） 作用： 静态资源、SSL 证书 HTTPS、端口转发、限流、防攻击；多实例负载均衡。

> 如果是微服务体系，会额外用：Spring Cloud Gateway / Kong / APISIX

------

## 四、数据库

### 关系数据库（必选其一）

- **MySQL 8.0**（绝大多数业务）
- PostgreSQL（复杂查询、地理数据） 配套：
- `mysqldump` 定时备份脚本；慢查询日志

### 缓存数据库

- **Redis** 缓存、分布式 Session、分布式锁、限流计数器、消息队列。

------

## 五、消息队列（异步业务）

业务量大就必须上；小型单体项目可以暂时不用

- RabbitMQ / RocketMQ / Kafka

> 作用：短信、邮件、日志、订单异步处理，削峰填谷。

------

## 六、持久化文件存储

方案 A：**本地磁盘**（小项目） 方案 B：MinIO（对象存储，自建，存图片、附件、文件） 方案 C：阿里云 / 腾讯云对象存储 OSS

------

## 七、监控套件（企业必备！）

1. **Prometheus + Grafana** 监控服务器 CPU、内存、磁盘、网络 + JVM 指标（GC、堆内存、线程数）
2. SpringBoot Actuator + Micrometer（程序暴露监控指标）
3. 日志：**ELK / EFK（Elasticsearch + Logstash + Filebeat + Kibana）** 收集所有后端日志，检索、排查线上 BUG

> 轻量替代：Loki

------

## 八、部署、CI/CD 自动化（持续发布）

- Git：拉取代码仓库
- Maven / Gradle：服务器打包，或者流水线预先打包 Jar 包
- **Jenkins**：自动化构建、自动部署；提交代码自动发布新版本 备选：GitLab CI / Gitee Go

## 九、容器方案（现在主流企业）

> 现在新项目大多容器化部署：

- Docker：打包应用环境
- Docker Compose（单服务器）
- Kubernetes K8s（集群多服务器、大型微服务）

------

# 实际

## 🅰️ 单体项目（中小型，单台服务器）

操作系统 + JDK + Nginx + MySQL + Redis 监控：Prometheus+Grafana，日志 ELK。
