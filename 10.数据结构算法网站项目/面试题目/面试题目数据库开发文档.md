# AlgoVize 面试题目 - 数据库开发文档

## 一、概述

本文档定义「面试题目」模块涉及的所有数据库表结构、字段说明、索引设计、ER 关系及初始化 SQL。

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **独立表** | 面试题目与 OJ 题目分表存储（`interview_problem` vs `oj_problem`），避免数据耦合 |
| **软删除** | 默认使用逻辑删除（`is_deleted = 1`），数据可恢复；物理删除仅限管理员慎用操作（API B8/B9），数据不可恢复 |
| **Markdown** | 题目描述、输入/输出格式、题解均为 Markdown 格式 |
| **UTF-8** | 所有表使用 `utf8mb4 / utf8mb4_unicode_ci`，兼容中文和 emoji |
| **审计字段** | 每张表包含 `created_at` / `updated_at`，记录变更时间 |

### 1.2 涉及的表

| 表名 | 用途 |
|------|------|
| `interview_problem` | 面试题目主表 |
| `interview_favorite` | 用户收藏记录表 |
| `interview_history` | 用户浏览历史记录表 |
| `interview_like` | 用户点赞点踩记录表 |
| `interview_tag` | 面试题目标签字典表（标签热度统计） |

## 三、表结构详解

### 3.1 面试题目主表：`interview_problem`

```sql
CREATE TABLE `interview_problem` (
    `id`                BIGINT          NOT NULL AUTO_INCREMENT    COMMENT '主键自增',
    `problem_no`        VARCHAR(32)     NOT NULL                   COMMENT '题目编号，唯一（如 MS001）',
    `title`             VARCHAR(255)    NOT NULL                   COMMENT '题目标题',
    `difficulty`        VARCHAR(20)     NOT NULL DEFAULT 'medium'  COMMENT '难度：easy / medium / hard',
    `tags`              VARCHAR(500)    DEFAULT NULL               COMMENT '标签，逗号分隔（如：数组,哈希表,双指针）',
    `category`          VARCHAR(50)     DEFAULT NULL               COMMENT '分类：数组/链表/树/图/动态规划/数学/其他',
    `description`       MEDIUMTEXT                                  COMMENT '题目描述（Markdown）',
    `input_format`      TEXT           DEFAULT NULL                COMMENT '输入格式（Markdown）',
    `output_format`     TEXT           DEFAULT NULL                COMMENT '输出格式（Markdown）',
    `solution`          MEDIUMTEXT     NOT NULL                    COMMENT '参考答案/题解（Markdown）',
    `status`            VARCHAR(20)    NOT NULL DEFAULT 'ACTIVE'   COMMENT '状态：ACTIVE=上线 / INACTIVE=下线',
    `is_frequent`       TINYINT(1)     DEFAULT 0                   COMMENT '是否高频：1=是 0=否',
    `is_deleted`        TINYINT(1)     DEFAULT 0                   COMMENT '逻辑删除：1=已删除 0=正常',
    `view_count`        INT            DEFAULT 0                   COMMENT '累计浏览数（阅读量）',
    `like_count`        INT            DEFAULT 0                   COMMENT '点赞数（冗余计数）',
    `dislike_count`     INT            DEFAULT 0                   COMMENT '点踩数（冗余计数）',
    `created_by`        VARCHAR(64)    DEFAULT NULL                COMMENT '创建人（管理员ID）',
    `updated_by`        VARCHAR(64)    DEFAULT NULL                COMMENT '最后更新人',
    `created_at`        DATETIME       DEFAULT CURRENT_TIMESTAMP   COMMENT '创建时间',
    `updated_at`        DATETIME       DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_interview_problem_no` (`problem_no`),
    KEY `idx_interview_filter` (`status`, `category`, `difficulty`, `is_deleted`),
    KEY `idx_interview_difficulty` (`difficulty`),
    KEY `idx_interview_is_frequent` (`is_frequent`),
    KEY `idx_interview_created_at` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='面试题目表';
```

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键，自增 |
| problem_no | VARCHAR(32) | 是 | 题目业务编号，唯一。建议前缀：MS=面试题，如 MS001、MS002 |
| title | VARCHAR(255) | 是 | 题目名称 |
| difficulty | VARCHAR(20) | 是 | 枚举：easy / medium / hard |
| tags | VARCHAR(500) | 否 | 知识点标签，逗号分隔，前端渲染为 chip |
| category | VARCHAR(50) | 否 | 大分类，用于「分类筛选」下拉 |
| description | MEDIUMTEXT | 否 | 题目描述，**Markdown 格式**，前台使用 markdown 渲染器展示 |
| input_format | TEXT | 否 | 输入格式说明，Markdown |
| output_format | TEXT | 否 | 输出格式说明，Markdown |
| solution | MEDIUMTEXT | 是 | 题目答案，**Markdown 格式** |
| status | VARCHAR(20) | 是 | ACTIVE=上线，前台可查询；INACTIVE=下线，仅后台可见 |
| is_frequent | TINYINT(1) | 否 | 高频标记，面试常考 |
| is_deleted | TINYINT(1) | 否 | 逻辑删除标记：1=已删除（B6 逻辑删除），0=正常 |
| view_count | INT | 否 | 累计浏览数（阅读量），前台访问详情时自动累加 |
| like_count | INT | 否 | 点赞数，冗余计数，与 interview_like 表保持同步 |
| dislike_count | INT | 否 | 点踩数，冗余计数，与 interview_like 表保持同步 |
| created_by | VARCHAR(64) | 否 | 创建管理员，用于审计 |
| updated_by | VARCHAR(64) | 否 | 最后修改管理员 |
| created_at | DATETIME | 否 | 创建时间 |
| updated_at | DATETIME | 否 | 更新时间，自动维护 |

> **逻辑删除 vs 下线**：`status = INACTIVE` 表示题目下线（仍在后台列表中可见，可重新上线）；`is_deleted = 1` 表示逻辑删除（从列表中移除，数据可恢复）。所有前台查询需同时满足 `status = 'ACTIVE' AND is_deleted = 0`。

### 3.2 用户收藏记录表：`interview_favorite`

```sql
CREATE TABLE `interview_favorite` (
    `id`           BIGINT        NOT NULL AUTO_INCREMENT    COMMENT '主键',
    `user_id`      BIGINT        NOT NULL                   COMMENT '用户ID（关联 user.id）',
    `problem_id`   BIGINT        NOT NULL                   COMMENT '题目ID（关联 interview_problem.id）',
    `problem_no`   VARCHAR(32)   DEFAULT NULL               COMMENT '冗余：题目编号（方便列表查询免关联）',
    `collect_time` DATETIME      DEFAULT CURRENT_TIMESTAMP  COMMENT '收藏时间',
    `created_at`   DATETIME      DEFAULT CURRENT_TIMESTAMP  COMMENT '创建时间',
    `updated_at`   DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_problem` (`user_id`, `problem_id`),
    KEY `idx_favorite_user_collect` (`user_id`, `collect_time`),
    KEY `idx_favorite_problem_id` (`problem_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='面试题目收藏表';
```

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键自增 |
| user_id | BIGINT | 是 | 用户 ID，联合唯一键 |
| problem_id | BIGINT | 是 | 题目 ID，联合唯一键 |
| problem_no | VARCHAR(32) | 否 | 冗余存储 problem_no，前台展示用 |
| collect_time | DATETIME | 否 | 收藏时间，用于收藏列表按时间倒序展示 |
| created_at | DATETIME | 否 | 记录创建时间 |
| updated_at | DATETIME | 否 | 记录更新时间 |

> **唯一约束**：同一用户对同一题目只能收藏一次，重复操作直接返回成功。
>
> **收藏列表说明**：收藏列表默认返回所有题目（含已下线），下线题目标注状态供用户感知。如需仅展示上线题目，前端可基于返回的 status 字段自行过滤。

### 3.3 用户浏览历史记录表：`interview_history`

```sql
CREATE TABLE `interview_history` (
    `id`          BIGINT        NOT NULL AUTO_INCREMENT    COMMENT '主键',
    `user_id`     BIGINT        NOT NULL                   COMMENT '用户ID（关联 user.id）',
    `problem_id`  BIGINT        NOT NULL                   COMMENT '题目ID（关联 interview_problem.id）',
    `view_time`   DATETIME      DEFAULT CURRENT_TIMESTAMP  COMMENT '浏览时间',
    `created_at`  DATETIME      DEFAULT CURRENT_TIMESTAMP  COMMENT '创建时间',
    `updated_at`  DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    KEY `idx_history_user_view` (`user_id`, `view_time`),
    KEY `idx_history_problem_id` (`problem_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='面试题目浏览历史表';
```

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键自增 |
| user_id | BIGINT | 是 | 用户 ID |
| problem_id | BIGINT | 是 | 题目 ID |
| view_time | DATETIME | 否 | 浏览时间，前台访问题目详情时自动记录 |
| created_at | DATETIME | 否 | 记录创建时间 |
| updated_at | DATETIME | 否 | 记录更新时间 |

> **浏览记录策略**：同一用户多次访问同一题目时，更新 `view_time` 为最新时间（不新增记录），浏览历史按 `view_time` 倒序排列。F8 删除单条历史按 `problem_id` 定位，F9 清空历史按 `user_id` 批量删除。

### 3.4 用户点赞点踩记录表：`interview_like`

```sql
CREATE TABLE `interview_like` (
    `id`          BIGINT        NOT NULL AUTO_INCREMENT    COMMENT '主键',
    `user_id`     BIGINT        NOT NULL                   COMMENT '用户ID（关联 user.id）',
    `problem_id`  BIGINT        NOT NULL                   COMMENT '题目ID（关联 interview_problem.id）',
    `type`        VARCHAR(10)   NOT NULL                   COMMENT '类型：like=点赞 / dislike=点踩',
    `created_at`  DATETIME      DEFAULT CURRENT_TIMESTAMP  COMMENT '创建时间',
    `updated_at`  DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_problem` (`user_id`, `problem_id`),
    KEY `idx_like_problem_id` (`problem_id`),
    KEY `idx_like_user_type` (`user_id`, `type`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='面试题目点赞点踩表';
```

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键自增 |
| user_id | BIGINT | 是 | 用户 ID，联合唯一键 |
| problem_id | BIGINT | 是 | 题目 ID，联合唯一键 |
| type | VARCHAR(10) | 是 | 类型：like=点赞 / dislike=点踩 |
| created_at | DATETIME | 否 | 记录创建时间 |
| updated_at | DATETIME | 否 | 记录更新时间 |

> **唯一约束**：同一用户对同一题目只能有一条记录（点赞或点踩），重复请求不重复计数。
>
> **计数同步**：用户点赞/点踩时，需同步原子更新 `interview_problem` 表的 `like_count` / `dislike_count` 冗余字段，前台 F2/F3 接口直接读取冗余字段避免实时聚合查询。

### 3.5 面试题目标签字典表：`interview_tag`

```sql
CREATE TABLE `interview_tag` (
    `id`         BIGINT        NOT NULL AUTO_INCREMENT,
    `name`       VARCHAR(50)   NOT NULL                   COMMENT '标签名（唯一）',
    `category`   VARCHAR(50)   DEFAULT NULL               COMMENT '标签分类',
    `use_count`  INT           DEFAULT 0                   COMMENT '使用次数（题目关联时自增）',
    `sort_order` INT           DEFAULT 0                   COMMENT '排序值（小在前）',
    `created_at` DATETIME      DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_tag_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='面试题目标签字典';
```

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键自增 |
| name | VARCHAR(50) | 是 | 标签名，唯一 |
| category | VARCHAR(50) | 否 | 标签分类 |
| use_count | INT | 否 | 使用次数，新增/修改题目时同步更新 |
| sort_order | INT | 否 | 排序值，小在前 |
| created_at | DATETIME | 否 | 创建时间 |
| updated_at | DATETIME | 否 | 更新时间 |

> **使用场景**：前台 F4「获取所有标签（按热度排序）」接口依赖此表，返回 `tagName`（对应 `name`）和 `useCount`（对应 `use_count`）。新增或修改题目时，解析 `tags` 字段并同步更新 `use_count`。

## 四、状态与枚举

### 4.1 难度 `difficulty`

| 值 | 含义 | 颜色 |
|----|------|------|
| easy | 简单 | 绿色 `#48c78a` |
| medium | 中等 | 黄色 `#fbbf24` |
| hard | 困难 | 红色 `#ef4444` |

### 4.2 状态 `status`

| 值 | 含义 | 前台可见 |
|----|------|----------|
| ACTIVE | 上线 / 正常 | ✅ 是 |
| INACTIVE | 下线 / 禁用 | ❌ 否 |

### 4.3 状态流转

```
新建 → ACTIVE (默认) ──(下线)──> INACTIVE
           ▲                          │
           └────────(重新上线)────────┘
```

> **注意**：`status` 控制上线/下线（B5 接口），`is_deleted` 控制逻辑删除（B6 接口），两者独立。逻辑删除的题目（`is_deleted=1`）不参与状态流转。

## 五、索引设计原则

| 索引 | 表 | 场景 |
|------|------|------|
| uk_interview_problem_no | interview_problem | 通过题号快速定位题目，确保题号唯一 |
| idx_interview_filter | interview_problem | 前台筛选查询（status + category + difficulty + is_deleted 联合索引） |
| idx_interview_difficulty | interview_problem | 后台按难度筛选 |
| idx_interview_is_frequent | interview_problem | 高频题筛选 |
| idx_interview_created_at | interview_problem | 按创建时间排序 |
| uk_user_problem | interview_favorite | 收藏去重（用户 + 题目） |
| idx_favorite_user_collect | interview_favorite | 收藏列表分页（用户 + 收藏时间） |
| idx_history_user_view | interview_history | 浏览历史分页（用户 + 浏览时间） |
| uk_user_problem | interview_like | 点赞去重（用户 + 题目） |
| uk_tag_name | interview_tag | 标签名唯一 |

## 七、前台查询时应关注的 SQL 示例

### 7.1 分页查询上线题目（搜索 + 难度 + 标签 + 分类）

```sql
SELECT *
FROM interview_problem
WHERE status = 'ACTIVE'
  AND is_deleted = 0
  AND difficulty = IFNULL(?, difficulty)
  AND (category = IFNULL(?, category) OR ? IS NULL)
  AND (title LIKE CONCAT('%', ?, '%') OR tags LIKE CONCAT('%', ?, '%'))
ORDER BY
  CASE WHEN ? = 'frequent' THEN is_frequent END DESC,
  id ASC
LIMIT ?, ?;
```

> 实际开发建议使用 MyBatis `<if>` 动态拼接 WHERE 条件。所有查询均需加上 `is_deleted = 0` 过滤逻辑删除的题目。

### 7.2 查询用户收藏列表

```sql
SELECT p.*, f.collect_time
FROM interview_favorite f
JOIN interview_problem p ON p.id = f.problem_id
WHERE f.user_id = ?
  AND p.is_deleted = 0
ORDER BY f.collect_time DESC
LIMIT ?, ?;
```

> 收藏列表默认返回所有题目（含已下线 status=INACTIVE），仅过滤逻辑删除（is_deleted=1）的题目。前端可基于返回的 status 字段标注下线状态供用户感知。

### 7.3 查询用户浏览历史

```sql
SELECT p.*, h.view_time
FROM interview_history h
JOIN interview_problem p ON p.id = h.problem_id
WHERE h.user_id = ?
  AND p.is_deleted = 0
ORDER BY h.view_time DESC
LIMIT ?, ?;
```

### 7.4 查询题目点赞点踩数

```sql
-- 直接读取冗余字段，无需聚合查询
SELECT like_count, dislike_count
FROM interview_problem
WHERE id = ? AND is_deleted = 0;
```
