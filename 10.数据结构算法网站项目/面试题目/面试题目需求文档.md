## 一、需求背景

当前面试准备场景中，求职者面临两个核心痛点：一是面试题目分散在各个平台，缺乏统一的练习和收藏管理入口；二是现有平台大多以刷题为主，缺少面试场景下的高频题标记、分类筛选和个人收藏整理能力。

本项目定位为独立的面试学习模块，聚焦于面试题目的查询浏览、个人收藏管理和后台题目维护。前台面向求职者提供题目检索、收藏夹管理、点赞互动等功能；后台面向管理员提供题目 CRUD、分类管理、批量导入导出等运营能力。

本文档仅覆盖题目相关的功能需求，不涉及用户账号管理模块。

---

## 二、角色定义

| 角色 | 使用场景 | 权限范围 |
|------|----------|----------|
| 前台用户（求职者） | 查询题目、浏览题解、管理收藏夹、点赞点踩 | 仅可操作个人收藏夹和点赞数据；可浏览已上线题目 |
| 后台管理员 | 题目增删改查、分类管理、题目上下线、批量导入导出 | 可操作所有题目和分类数据；不可管理用户账号 |

#### 业务逻辑

用户进入题目列表页后，系统默认展示全部已上线题目，按创建时间倒序排列。用户可通过顶部搜索栏输入关键词，系统在标题和标签两个字段中进行模糊匹配。筛选区提供难度（简单/中等/困难）、分类（数组/链表/树等）、标签（单选精确匹配）三个维度的下拉筛选，以及"仅看高频题"开关。排序方式支持按浏览量降序和默认排序两种。

用户点击列表中任意题目卡片，跳转到题目详情页。详情页以 Markdown 格式渲染题目描述、输入格式、输出格式和题解四个内容区块，代码块需语法高亮。每次访问详情页，系统自动将该题目的浏览量加 1，并在用户登录状态下记录到浏览历史。

底部操作栏提供收藏、点赞、点踩三个操作入口。收藏按钮点击后弹出收藏夹选择面板（详见 3.2 收藏夹管理）。点赞和点踩为互斥操作，同一用户对同一题目只能有一个有效状态，重复点击同一操作取消该状态。

#### 交互逻辑

| 用户操作 | 系统响应 | 页面状态变化 |
|----------|----------|-------------|
| 输入关键词并搜索 | 按标题和标签模糊匹配，返回匹配题目列表 | 列表刷新，保留当前筛选条件 |
| 选择难度筛选 | 过滤对应难度的题目 | 列表刷新，筛选标签显示当前选择 |
| 切换"仅看高频" | 过滤 is_frequent=1 的题目 | 列表刷新，开关高亮 |
| 点击题目卡片 | 跳转详情页，浏览量+1 | 页面跳转 |
| 点击收藏按钮 | 弹出收藏夹选择面板 | 弹出层显示 |
| 点击点赞按钮 | 记录点赞，点赞数+1 | 按钮高亮，点踩按钮取消高亮 |
| 再次点击点赞 | 取消点赞，点赞数-1 | 按钮恢复默认状态 |
| 点击点踩按钮 | 记录点踩，点踩数+1 | 按钮高亮，点赞按钮取消高亮 |

#### 字段规则

| 字段名称 | 类型 | 必填 | 长度/范围 | 默认值 | 说明 |
|----------|------|------|-----------|--------|------|
| keyword | String | 否 | 1-50 字符 | 空 | 搜索关键词，匹配标题和标签 |
| difficulty | String | 否 | easy/medium/hard | 全部 | 难度筛选 |
| category | String | 否 | 枚举值 | 全部 | 分类筛选 |
| tag | String | 否 | 1-20 字符 | 空 | 单标签精确匹配 |
| onlyFrequent | Integer | 否 | 0/1 | 0 | 仅看高频题开关 |
| page | Integer | 否 | ≥1 | 1 | 当前页码 |
| pageSize | Integer | 否 | 20/50/100 | 20 | 每页条数 |
| sortBy | String | 否 | id/viewCount | id | 排序字段 |
| order | String | 否 | asc/desc | desc | 排序方向 |

#### 权限逻辑

| 角色 | 可见范围 | 可操作内容 |
|------|----------|-----------|
| 游客（未登录） | 所有已上线题目（status=ACTIVE, is_deleted=0） | 仅查询和浏览，不可点赞收藏 |
| 登录用户 | 所有已上线题目 | 查询、浏览、收藏、点赞、点踩 |
| 管理员 | 所有题目（含下线） | 通过后台管理界面操作 |

#### 边界与异常

- 搜索关键词为空时展示全部题目，不做筛选
- 筛选结果为空时显示"暂无匹配题目"空状态页
- 题目详情页的题解内容默认展开显示（面试学习场景需要直接看到答案）
- 未登录用户点击收藏/点赞时，弹出登录提示

#### 业务逻辑

每个用户拥有一组个人收藏夹，系统在用户首次使用时自动创建一个"默认收藏夹"。用户可自行创建新的收藏夹，每个收藏夹包含名称（必填，不超过 20 字符）和备注（选填，不超过 100 字符）两个字段。同一用户的收藏夹名称不可重复。

用户在题目详情页点击收藏按钮后，弹出收藏夹选择面板，展示该用户所有收藏夹列表（单选）。用户选择目标收藏夹后点击"确定收藏"，系统将题目添加到对应收藏夹中。同一题目可被收藏到多个不同收藏夹中，但同一收藏夹内同一题目只保留一条记录，重复收藏直接返回成功。

收藏夹管理页面左侧展示所有收藏夹列表及每个收藏夹内的题目数量，右侧展示选中收藏夹内的题目列表。列表按收藏时间倒序排列，每条记录显示题目编号、标题、难度标签和收藏时间。用户可对收藏夹内的题目执行取消收藏操作，将题目从当前收藏夹中移除。

用户可对收藏夹执行重命名和删除操作。删除收藏夹时，该收藏夹内的所有收藏关系一并删除，但题目本身不受影响。删除操作需二次确认，提示"删除收藏夹将同时移除该收藏夹内的所有收藏记录，确定删除？"

#### 交互逻辑

| 用户操作 | 系统响应 | 页面状态变化 |
|----------|----------|-------------|
| 点击"新建收藏夹" | 弹出新建弹窗 | 弹窗显示 |
| 输入名称并创建 | 创建收藏夹，刷新侧栏 | 新收藏夹出现在侧栏列表 |
| 点击收藏夹名称 | 加载该收藏夹内题目列表 | 右侧列表刷新 |
| 点击"管理收藏夹" | 进入收藏夹管理模式 | 每个收藏夹旁出现重命名和删除按钮 |
| 点击重命名 | 弹出重命名弹窗，预填当前名称 | 弹窗显示 |
| 点击删除收藏夹 | 弹出二次确认弹窗 | 确认弹窗显示 |
| 确认删除 | 删除收藏夹及内部收藏关系 | 侧栏列表刷新 |
| 在详情页点击收藏 | 弹出收藏夹选择面板 | 弹出层显示 |
| 选择收藏夹并确定 | 将题目加入选中收藏夹 | 收藏按钮变为已收藏状态 |
| 在收藏列表点击取消收藏 | 将题目从当前收藏夹移除 | 该条目从列表消失 |

#### 字段规则

收藏夹字段：

| 字段名称 | 类型 | 必填 | 长度/范围 | 默认值 | 说明 |
|----------|------|------|-----------|--------|------|
| folderName | String | 是 | 1-20 字符 | 无 | 收藏夹名称，同用户下唯一 |
| description | String | 否 | 0-100 字符 | 空 | 收藏夹备注描述 |

收藏关系字段：

| 字段名称 | 类型 | 必填 | 长度/范围 | 默认值 | 说明 |
|----------|------|------|-----------|--------|------|
| problemId | Long | 是 | — | 无 | 被收藏的题目 ID |
| folderId | Long | 是 | — | 无 | 目标收藏夹 ID |

#### 状态流转

收藏夹无复杂状态流转，仅存在"正常"和"已删除"两种状态。收藏关系存在"已收藏"和"已取消"两种状态，取消后物理删除该收藏关系记录。

#### 权限逻辑

| 角色 | 可见范围 | 可操作内容 |
|------|----------|-----------|
| 登录用户 | 仅自己的收藏夹和收藏记录 | 创建/重命名/删除自己的收藏夹；收藏/取消收藏题目 |
| 游客 | 无 | 不可访问收藏功能 |

#### 边界与异常

- 收藏夹名称重复时提示"该收藏夹名称已存在，请更换"
- 删除"默认收藏夹"时提示"默认收藏夹不可删除"
- 收藏夹数量上限为 20 个，超出时提示"收藏夹数量已达上限"
- 收藏的题目被管理员下线后，收藏列表中仍展示该题目但标注"已下线"状态
- 收藏的题目被管理员删除后，收藏列表中自动移除该条目

### 3.3 点赞点踩（前台用户）

#### 页面布局

点赞点踩功能嵌入在题目详情页底部操作栏中：

```
┌─────────────────────────────────────────────┐
│  底部操作栏                                  │
├─────────────────────────────────────────────┤
│                                             │
│   [☆ 收藏]    [👍 点赞 320]   [👎 点踩 12]  │
│                                             │
│   (未操作状态：按钮为描边样式)                │
│                                             │
├─────────────────────────────────────────────┤
│                                             │
│   [★ 已收藏]  [👍 已点赞 321]   [👎 点踩 12] │
│                                             │
│   (已操作状态：按钮为填充高亮样式)            │
│                                             │
└─────────────────────────────────────────────┘
```

#### 业务逻辑

每个登录用户可对任意已上线题目进行点赞或点踩操作。点赞和点踩为互斥关系：用户对同一题目只能有一个有效状态，即如果用户已点赞，点击点踩按钮会自动取消点赞并切换为点踩状态，反之亦然。

用户再次点击当前已激活的操作按钮（如已点赞状态下再点击点赞），则取消该操作，恢复到未操作状态。取消操作后点赞数或点踩数相应减 1。

题目列表页和详情页均展示点赞数。点赞数为冗余计数字段，存储在题目主表中，通过原子更新维护，避免每次查询时实时聚合统计。

#### 交互逻辑

| 当前状态 | 用户操作 | 系统响应 | 操作后状态 |
|----------|----------|----------|-----------|
| 未操作 | 点击点赞 | 记录点赞，like_count+1 | 已点赞 |
| 未操作 | 点击点踩 | 记录点踩，dislike_count+1 | 已点踩 |
| 已点赞 | 点击点赞 | 取消点赞，like_count-1 | 未操作 |
| 已点赞 | 点击点踩 | 取消点赞 like_count-1，记录点踩 dislike_count+1 | 已点踩 |
| 已点踩 | 点击点踩 | 取消点踩，dislike_count-1 | 未操作 |
| 已点踩 | 点击点赞 | 取消点踩 dislike_count-1，记录点赞 like_count+1 | 已点赞 |

#### 字段规则

| 字段名称 | 类型 | 必填 | 长度/范围 | 默认值 | 说明 |
|----------|------|------|-----------|--------|------|
| problemId | Long | 是 | — | 无 | 题目 ID |
| type | String | 是 | like/dislike | 无 | 操作类型 |

#### 权限逻辑

| 角色 | 可见范围 | 可操作内容 |
|------|----------|-----------|
| 游客 | 可查看点赞/点踩数量 | 不可执行点赞/点踩操作 |
| 登录用户 | 可查看数量和自身操作状态 | 可对任意已上线题目点赞或点踩 |

#### 边界与异常

- 未登录用户点击点赞/点踩时弹出登录提示
- 题目被下线后，已点赞/点踩的记录保留，但用户无法再对该题目操作
- 并发场景下通过数据库唯一约束（user_id + problem_id）保证同一用户只有一条有效记录

#### 业务逻辑

管理员进入题目管理页面后，系统展示全部题目（含上线和下线状态），按创建时间倒序排列。顶部筛选区支持按关键词、难度、分类、状态、是否高频五个维度筛选。表格每行展示题目编号、标题、难度标签、分类、状态和操作按钮。操作按钮包括编辑、上线/下线切换、删除三个选项。

管理员点击"新增题目"弹出新增弹窗，填写题目编号（选填，留空时系统自动按 MS+递增数字格式生成）、标题（必填）、难度（必填）、分类（选填）、标签（选填）、题目描述/输入格式/输出格式/题解（Markdown 格式，题解必填）、是否高频（选填）。保存后题目默认为上线状态（ACTIVE）。

编辑题目时弹窗预填当前题目数据，管理员修改后保存即可。编辑弹窗中题目状态可在此处切换。

上线/下线操作直接切换题目 status 字段。下线题目在前台不可见，但后台列表中仍展示并标注状态。

删除操作分两种：逻辑删除（默认）将题目标记为 is_deleted=1，从前后台列表中移除但数据可恢复；物理删除（需二次确认）永久删除题目数据不可恢复。批量删除时默认使用逻辑删除。

批量导入支持上传 JSON 格式的题目文件，系统自动解析并批量入库，返回成功数和失败数及失败原因。批量导出可将当前筛选条件下的题目导出为 JSON 文件下载。

AI 生成功能调用 DeepSeek 模型，管理员配置分类、难度、数量后点击生成，系统同步返回 AI 生成的题目预览列表。管理员可逐题编辑修改后，勾选需要入库的题目点击"一键入库"，系统将选中的题目批量保存到题库。

#### 边界与异常

- AI 生成接口超时时间 60 秒，调用频率限制每分钟 5 次
- AI 生成失败时提示"AI 服务暂时不可用，请稍后重试"
- 文件上传限制：仅允许 .json 格式，大小不超过 10MB，单次导入不超过 500 条
- Markdown 内容存储前需过滤原始 HTML 标签，前端渲染时使用 DOMPurify 净化防 XSS

## 四、模块关联说明

### 4.1 分类与题目的关系

分类管理（3.5）中维护的分类列表是题目管理（3.4）中分类字段的选项来源。新增或编辑题目时，分类下拉框的选项从分类表中实时加载。删除分类时需确保无关联题目，保证数据一致性。

### 4.2 收藏夹与题目的关系

用户通过题目详情页（3.1）的收藏按钮触发收藏操作，收藏目标收藏夹在收藏夹管理（3.2）中维护。题目被下线后仍保留在收藏列表中但标注状态；题目被删除后自动从收藏列表中移除。

### 4.3 点赞与题目的关系

点赞点踩（3.3）操作在题目详情页（3.1）触发，点赞数冗余存储在题目主表中，列表页和详情页均直接读取冗余字段展示，避免实时聚合查询。
