# 功能要求

## **性能要求**

**本地**

| 接口分类                           | 本地平均 RT    | 说明                                                         |
| ---------------------------------- | -------------- | ------------------------------------------------------------ |
| 核心轻量接口（登录、获取用户信息） | **≤100‑150ms** | 你的登录本地稳定 200ms，属于偏高，需要排查；冷启动前几次允许 200‑300ms，预热后回落 |
| 普通业务查询（列表分页）           | ≤200ms         | 简单分页查询                                                 |
| 复杂查询（多表、统计、大分页）     | ≤500ms         | 允许复杂业务慢一点                                           |

**线上**

| 接口分类                                       | 平均 RT (ms) | P95(ms) | P99(ms) | 5xx 错误率 | 说明                                         |
| ---------------------------------------------- | ------------ | ------- | ------- | ---------- | -------------------------------------------- |
| 核心入口接口（登录、获取用户权限、Token 校验） | ≤200         | ≤300    | ≤500    | ＜0.5%     | 用户第一道访问链路，严控长尾耗时             |
| 普通业务接口（分页列表、简单单表查询）         | ≤400         | ≤600    | ≤1000   | ＜0.5%     | 普通 CRUD、题解 / 评论列表查询等             |
| 复杂查询接口（多表联查、多条件过滤）           | ≤600         | ≤1000   | ≤1500   | ＜1%       | 多表 Join、复杂 where 条件，避免深度嵌套查询 |
| 统计 / 报表 / 大数据同步查询                   | ≤1000        | ≤2000   | ≤3000   | ＜1%       | 优先使用缓存、异步任务，禁止长同步阻塞       |

**🔐安全模块**

- 密码加密：BCrypt、MD5 加盐、SHA256

- 密钥统一管理、密钥轮换
- 文件上传安全校验
- **请求参数大小限制、请求体拦截**：防大报文攻击、DoS；限制上传文件 MIME、文件头魔数校验（不仅仅后缀）；防止恶意压缩包炸弹

- **敏感接口防爬虫：人机校验（滑块 / 验证码触发）**
- **数据导出安全管控**：大数据导出权限控制、导出审计、导出频率限制，防止批量拖库
- **依赖组件安全管控**：第三方依赖漏洞扫描（Trivy/SonarQube）；依赖版本基线；漏洞告警
- **业务权限越权检测**：横向越权、纵向越权防护（框架层拦截，不止业务代码）

**加密算法**

1. **用户密码存储**：用户密码采用 Argon2id/BCrypt 这类单向 KDF 慢哈希算法，不可逆，禁止使用对称、非对称加密存储密码。
2. **完整性摘要**：文件、参数防篡改使用 SHA‑256 做哈希摘要，淘汰 MD5、SHA1，国密场景替换为 SM3。
3. **敏感隐私字段加密**：手机号、身份证这类需要解密读出的业务隐私数据，使用 AES‑256‑GCM 对称加密，国密选用 SM4，密钥交由 KMS 管理。
4. **签名与密钥交换**：接口、JWT 签名优先 ECC‑ES256，老旧对接使用 RSA‑4096；非对称只做签名和加密会话密钥，不加密大报文，国密选用 SM2。
5. **网络传输安全**：通信链路依靠 TLS1.3 完成 HTTPS 加密，业务代码无需手动实现底层加解密。
6. **数字信封机制**：大报文用 AES 加密，再用非对称算法加密 AES 密钥，解决非对称无法处理大数据的问题。
7. **国密适配**：政务金融国密环境，密码派生 PBKDF2‑HMAC‑SM3、摘要 SM3、对称 SM4、非对称 SM2 全套替换国际算法。
8. **避坑核心**：严禁硬编码密钥；AES 禁用 ECB 模式；RSA 不要加密业务明文；密码永远不能可逆存储。

# 项目标准规范

**DTO入参 -参数校验-VO出参 全局统一异常处理 + 自定义异常体系**

| 对象    | 角色       | 数据来源                  | 能不能修改原始业务数据            |
| ------- | ---------- | ------------------------- | --------------------------------- |
| **DTO** | 入参对象   | 前端传过来                | ❌不存数据库原始数据               |
| **BO**  | 业务对象   | Service 内部流转，来自 DO | ✅保存业务原始明文数据             |
| **DO**  | 数据库实体 | 数据库查询结果            | ✅数据库原始完整数据               |
| **VO**  | 视图对象   | BO 转换而来               | ✅做脱敏、过滤、格式化，只用于展示 |

```
前端请求
    ↓
【DTO】 接收前端传入参数 → Controller
    ↓
Controller 把 DTO 转换为【BO】传给 Service
    ↓
【BO】业务层内部流转（Service / ServiceImpl 处理业务）
    ↓
ServiceImpl 将 BO 转换为【DO】调用 Mapper
    ↓
【DO】Mapper 和数据库交互（数据库实体）
    ↓
数据库返回数据 → Mapper 返回 DO
    ↓
ServiceImpl 把 DO 转为【BO】
    ↓
Controller 将【BO】转为【VO】
    ↓
【VO】Controller 返回给前端
```

**完整链路请求：**  SpringBoot 接收请求 → 参数校验 → 登录鉴权 (JWT) →会话管理 → 业务逻辑 → 调用数据库 → 返回结果，全局异常处理→ 返回前端渲染

**完整响应链条**：

```
前端请求
  → Nginx 反向代理 + 跨域处理
  → 过滤器链：字符编码 → CORS → 请求体重复读
  → 拦截器：JWT 鉴权 → Redis 校验 Token 有效性 → 获取当前用户
  → AOP 切面：操作日志记录 → 接口限流校验 → 幂等令牌校验
  → Controller 层：参数校验（@Valid） → 接收请求 → 调用 Service
  → Service 层：业务逻辑处理 → 事务控制 → 读写 Redis 缓存 → MySQL
  → Mapper 层：MyBatis-Plus 操作 MySQL → 数据返回
  → 结果封装：统一 Result<T> 包装 → 异常统一捕获转换
  → 响应返回前端
```

# 防网络攻击

## 1️⃣输入校验防护（所有攻击入口，最核心）

> 一切外部输入都不可信：URL 参数、Header、Body、Cookie、表单、文件上传

1. SQL 注入防护
   - 禁止字符串拼接 SQL，全部使用预编译参数；禁止 MyBatis `${}` 直接接收用户输入；高危 SQL 拦截。
2. XSS 跨站脚本攻击
   - 后端输出 HTML 特殊字符转义；接口返回 JSON 避免注入脚本；前端 CSP 策略。
3. 命令注入 / 路径遍历
   - 禁止直接把用户输入传给系统命令、文件路径；文件名、路径做白名单校验。
4. 请求参数校验
   - JSR‑303 参数校验；参数长度、格式、范围白名单；拒绝超大请求 Body。
5. 文件上传攻击
   - 文件后缀校验、文件魔数头校验；防压缩炸弹；禁止上传可执行脚本；上传目录禁止执行权限。

## 2️⃣会话与身份认证攻击防护

1. 会话劫持

   - Token / Cookie 配置：`HttpOnly、Secure、SameSite`；会话绑定设备指纹；会话固定攻击防护。

2. 暴力破解

   - 登录接口限流、账号锁定、验证码；密码复杂度策略。

3. CSRF 跨站请求伪造

   - SameSite Cookie；接口 CSRF‑Token 校验；禁止简单 Cookie 自动鉴权。

4. JWT/Refresh‑Token 安全

   - 短有效期；refresh‑token 维护 jti 黑名单；密钥禁止硬编码；禁止弱密钥。

5. 越权攻击（重点）

   - **纵向越权**：低权限访问高权限接口；
   - **横向越权**：A 用户访问 B 用户的数据；

   > 注意：前端权限只是 UI 隐藏，**必须后端接口层做权限校验**。

## 3️⃣接口业务层攻击防护

1. 接口重放攻击
   - 时间戳 + nonce + 请求签名；校验时间窗口，防止报文被抓包重复调用。
2. 接口防刷、CC 攻击
   - 接口粒度限流（IP、账号维度）；区分登录失败限流；高频查询接口限制 QPS。
3. 重复提交（幂等）
   - 幂等注解；业务唯一请求号；防止表单重复提交、MQ 重复消费。
4. 敏感操作防护
   - 二次身份校验；导出数据频率 & 权限管控，防止批量拖库。

## 4️⃣网络传输与网络层防护

1. TLS/HTTPS
   - 禁用老旧 TLS1.0/TLS1.1，使用 TLS1.3；强制 HTTPS；证书有效期监控。
2. IP 黑白名单
   - 后台管理接口限制访问来源 IP。
3. CORS 跨域安全
   - Origin 白名单，禁止配置`*`高危策略。
4. WAF 防护（网关层）
   - 拦截恶意 payload、扫描器攻击；防护 DoS。

## 5️⃣数据输出侧安全

1. 数据脱敏
   - 手机号、身份证返回接口脱敏；日志禁止打印敏感明文。
2. 接口水印溯源
   - 敏感接口返回报文携带水印，泄露事后溯源取证。
3. 错误信息泄露
   - 全局统一异常处理，不对外输出堆栈、数据库原始报错；内部错误日志完整记录。

## 6️⃣代码、依赖与组件安全

1. 第三方依赖漏洞
   - SonarQube / Trivy 扫描；依赖版本基线，修复高危 CVE 漏洞。
2. JDK/JUL 组件安全
   - 收紧 JUL 日志级别；防止底层组件异常信息泄露。
3. 密钥安全
   - 密钥统一 KMS 管理；禁止硬编码密钥；支持密钥轮换；AES 禁止 ECB 模式。
4. AOP 切面安全
   - 切面不要绕过权限校验；审计日志记录攻击行为。

## 7️⃣运维 & 审计检测（发现攻击）

1. 安全审计日志
   - 登录、权限变更、敏感操作、异常访问全部留痕；日志不可篡改。
2. 告警
   - 频繁登录失败、越权访问、高频请求触发钉钉 / 邮件告警。
3. 链路 TraceId，攻击发生可以完整还原请求链路。
