**加密算法**

1. **用户密码存储**：用户密码采用 Argon2id/BCrypt 这类单向 KDF 慢哈希算法，不可逆，禁止使用对称、非对称加密存储密码。
2. **完整性摘要**：文件、参数防篡改使用 SHA‑256 做哈希摘要，淘汰 MD5、SHA1，国密场景替换为 SM3。
3. **敏感隐私字段加密**：手机号、身份证这类需要解密读出的业务隐私数据，使用 AES‑256‑GCM 对称加密，国密选用 SM4，密钥交由 KMS 管理。
4. **签名与密钥交换**：接口、JWT 签名优先 ECC‑ES256，老旧对接使用 RSA‑4096；非对称只做签名和加密会话密钥，不加密大报文，国密选用 SM2。
5. **网络传输安全**：通信链路依靠 TLS1.3 完成 HTTPS 加密，业务代码无需手动实现底层加解密。
6. **数字信封机制**：大报文用 AES 加密，再用非对称算法加密 AES 密钥，解决非对称无法处理大数据的问题。
7. **国密适配**：政务金融国密环境，密码派生 PBKDF2‑HMAC‑SM3、摘要 SM3、对称 SM4、非对称 SM2 全套替换国际算法。
8. **避坑核心**：严禁硬编码密钥；AES 禁用 ECB 模式；RSA 不要加密业务明文；密码永远不能可逆存储。

**完整链路请求：**  SpringBoot 接收请求 → 参数校验 → 登录鉴权 (JWT) →会话管理 → 业务逻辑 → 调用数据库 → 返回结果，全局异常处理→ 返回前端渲染

**完整响应链条**：

```
前端请求
  → Nginx 反向代理 + 跨域处理
  → 过滤器链：字符编码 → CORS → 请求体重复读
  → 拦截器：JWT 鉴权 → Redis 校验 Token 有效性 → 获取当前用户
  → AOP 切面：操作日志记录 → 接口限流校验 → 幂等令牌校验
  → Controller 层：参数校验（@Valid） → 接收请求 → 调用 Service
  → Service 层：业务逻辑处理 → 事务控制 → 读写 Redis 缓存 → MySQL
  → Mapper 层：MyBatis-Plus 操作 MySQL → 数据返回
  → 结果封装：统一 Result<T> 包装 → 异常统一捕获转换
  → 响应返回前端
```

# controll 功能开发

定位：标准中型单体算法OJ系统，纯刷题、判题、竞赛、用户权限、系统管理，**完全剔除视频/B站相关业务**，架构干净、适配企业级单体开发规范。

规范：一个 Controller 对应一类业务资源，单 Controller 控制在 5-15 个接口、800 行代码内，无臃肿堆砌。

## 一、完整 Controller 清单（总计22个，纯净OJ业务）

### 🔐 基础权限用户模块（6个）

负责系统登录认证、用户管理、角色权限、文件通用能力

- **AuthController**：登录、注销、刷新Token、验证码、游客访问控制
- **UserController**：前台用户注册、个人信息、修改密码、头像更换、刷题数据概览
- **AdminUserController**：后台用户管理、账号禁用、重置密码、用户列表查询
- **RoleController**：角色新增、编辑、删除、角色分配
- **PermissionController**：菜单权限、按钮权限配置、权限树查询
- **FileController**：通用文件上传、下载、预签名URL生成、头像/附件文件管理

### 📝 OJ核心刷题模块（8个）

OJ核心业务，题目管理、测试用例、代码提交、判题逻辑

- **ProblemController**：题目CRUD、前台题目列表、题目详情、难度筛选、搜索
- **ProblemTagController**：算法标签管理（贪心、动态规划、二分）、题目标签绑定解绑
- **ProblemCategoryController**：题目分类、难度分类、学科分类管理
- **TestCaseController**：测试用例上传、下载、新增、删除、判题数据管理
- **SubmitController**：用户代码提交、提交记录查询、代码回看、提交统计
- **JudgeController**：判题机回调、判题状态查询、判题任务管理、异常重试
- **CodeTemplateController**：代码模板管理、不同语言默认模板配置

### 🏆 竞赛对战模块（4个）

在线算法竞赛、限时刷题比赛、排行榜

- **ContestController**：竞赛创建、编辑、启停、竞赛列表、竞赛详情
- **ContestProblemController**：竞赛题目绑定、题目顺序配置、分数配置
- **ContestUserController**：用户报名参赛、参赛名单管理
- **ContestRankController**：实时竞赛排行榜、赛后榜单快照

### 📊 系统统计与管理模块（4个）

后台运维、数据统计、系统配置、审计留痕

- **AuditLogController**：操作审计日志查询、后台操作留痕追溯
- **StatisticController**：刷题统计、通过率统计、用户活跃度、数据大盘
- **NoticeController**：系统公告发布、编辑、前台公告展示
- **SystemConfigController**：系统全局配置、判题机参数、网站参数配置

### 🧩 辅助功能模块（2个）

- **FeedbackController**：用户问题反馈、管理员查看处理
- **RankController**：全站刷题总排行榜、用户积分排名
