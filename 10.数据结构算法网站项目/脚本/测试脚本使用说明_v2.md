## 1. 环境准备

### 1.1 安装 Python 依赖

```bash
pip install requests pytest pytest-html
```

### 1.2 环境变量配置（可选）

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `ALGOVIZE_BASE_URL` | 后端服务地址 | `http://localhost:80` |
| `ALGOVIZE_TIMEOUT` | 请求超时时间(秒) | `10` |
| `ALGOVIZE_TEST_USER` | 测试用户名 | `testuser` |
| `ALGOVIZE_TEST_PASS` | 测试用户密码 | `123456` |
| `ALGOVIZE_TEST_USER2` | 第二测试用户名 | `testuser2` |
| `ALGOVIZE_TEST_PASS2` | 第二测试用户密码 | `123456` |
| `ALGOVIZE_ADMIN_USER` | 管理员用户名 | `admin` |
| `ALGOVIZE_ADMIN_PASS` | 管理员密码 | `admin123` |

### 1.3 启动后端服务

确保后端 Spring Boot 服务已启动，监听在配置的端口上。

## 2. 运行测试

### 2.1 运行所有测试

```bash
cd d:\daima\XiangMu\算法数据结构可视化
python doc/tools/test_api_v2.py
```

### 2.2 运行指定测试类

```bash
# 仅运行认证测试
python -m pytest doc/tools/test_api_v2.py -k TestAuth -v

# 仅运行 OJ 题目测试
python -m pytest doc/tools/test_api_v2.py -k TestOJProblem -v

# 仅运行安全性测试
python -m pytest doc/tools/test_api_v2.py -k TestSecurity -v
```

### 2.3 运行指定测试方法

```bash
# 仅测试登录功能
python -m pytest doc/tools/test_api_v2.py -k test_login_success -v

# 仅测试 ID 排序
python -m pytest doc/tools/test_api_v2.py -k test_sort_by_id_asc -v
```

### 2.4 生成 HTML 报告

```bash
python -m pytest doc/tools/test_api_v2.py --html=doc/tools/report.html --self-contained-html
```

### 2.5 生成 JUnit XML 报告（CI 用）

```bash
python -m pytest doc/tools/test_api_v2.py --junitxml=doc/tools/report.xml
```

### 2.6 带覆盖率统计

```bash
pip install pytest-cov
python -m pytest doc/tools/test_api_v2.py --cov=algoviz --cov-report=html
```

### 4.2 测试通过标记说明

| 标记 | 含义 |
|------|------|
| PASSED | 测试用例通过 |
| FAILED | 测试用例失败（有断言不满足） |
| SKIPPED | 测试用例跳过（前置条件不满足，如无测试数据） |
| ERROR | 测试用例执行异常（代码错误） |

### 4.3 常见问题处理

| 问题 | 解决方案 |
|------|---------|
| `后端服务不可用` | 检查后端服务是否启动，端口是否正确 |
| `登录失败: HTTP 500` | 检查数据库连接是否正常 |
| `没有可测试的题目` | 数据库中需要有题目数据 |
| `没有可测试的题解` | 先发布题解再运行测试 |
| `ImportError` | 运行 `pip install requests pytest` |

## 5. 扩展自定义测试

### 5.1 添加新测试类

```python
class TestNewFeature:
    """新功能测试"""
    
    def test_new_endpoint(self, api: APIClient, user_token: str):
        """测试新接口"""
        Config.log("测试: 新接口", "INFO")
        resp = api.get("/api/new-endpoint", token=user_token)
        assert resp.status_code == 200
        Config.log("✅ 新接口测试通过", "SUCCESS")
```

### 5.2 添加新测试账号

```bash
# Windows PowerShell
$env:ALGOVIZE_TEST_USER = "newuser"
$env:ALGOVIZE_TEST_PASS = "newpass"
python doc/tools/test_api_v2.py
```

### 5.3 修改超时时间

```bash
# 设置超时为 30 秒
$env:ALGOVIZE_TIMEOUT = "30"
python doc/tools/test_api_v2.py
```

## 6. CI/CD 集成示例

### 6.1 GitLab CI

```yaml
# .gitlab-ci.yml
stages:
  - test

api_test:
  stage: test
  image: python:3.11
  script:
    - pip install requests pytest
    - python doc/tools/test_api_v2.py --junitxml=report.xml
  artifacts:
    when: always
    reports:
      junit: doc/tools/report.xml
    paths:
      - doc/tools/report.html
```

### 6.2 GitHub Actions

```yaml
# .github/workflows/test.yml
name: API Tests
on: [push, pull_request]
jobs:
  api-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: pip install requests pytest
      - run: python doc/tools/test_api_v2.py --junitxml=report.xml
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: test-report
          path: doc/tools/report.xml
```

## 7. 与文档配合使用

1. 查看 `doc/AlgoVize_完整测试文档_v2.md` 了解完整测试用例
2. 运行 `python doc/tools/test_api_v2.py` 执行自动化测试
3. 对比文档中的预期结果与脚本实际执行结果
4. 对 FAIL 用例进行人工复核
5. 补充 SKIP 用例的前置条件后重新运行
