# SpringBoot 后台网站完整能力清单

分为：**基础框架能力、用户权限体系、业务核心、存储、对外调用、运维监控、安全、前端交互适配、扩展能力**。

1. 密码加密：BCrypt、MD5 加盐、SHA256 
2. 接口防重放：时间戳 + 随机 nonce 签名 
3. 数据脱敏：数据库存储脱敏、接口返回脱敏（手机号 / 身份证） 
4. 数据加密传输：接口 AES 加密 
5. 权限细化：按钮权限、数据行权限、字段权限

**完整链路请求：**  SpringBoot 接收请求 → 参数校验 → 登录鉴权 (JWT) →会话管理 → 业务逻辑 → 调用数据库 → 返回结果，全局异常处理→ 返回前端渲染

## 一、基础框架 & 请求处理（必做）

1. **HTTP 接口接收请求**（RestController）

2. **入参校验**：`@Valid`、非空、长度、格式校验，拦截非法参数

3. 全局异常处理

   ```
   @RestControllerAdvice
   ```

   - 业务异常、系统异常、LLM 调用异常统一捕获
   - 统一返回格式：`{code,msg,data}`，不要直接抛堆栈给前端

4. **跨域 CORS 配置**，适配 Vue/React 前端

5. 接口日志拦截器

   - 记录：用户 ID、请求 URL、入参、响应、耗时、IP

6. 接口限流防刷

   - 按用户 / IP 限流，尤其 LLM 接口，防止恶意调用消耗 token；Sentinel / Redis + AOP

7. **统一返回封装**，所有响应格式标准化

## 二、用户、登录、鉴权、会话（后台系统核心）

> 可选方案：SpringSecurity / Sa‑Token / JWT

1. **登录接口**：账号密码登录、验证码登录
2. **登出接口**、会话销毁
3. Token 管理
   - AccessToken + RefreshToken 刷新机制
   - Token 黑名单（登出立刻失效）
4. RBAC 权限体系（管理后台必备）
   - 用户、角色、菜单、接口权限
   - 接口级权限控制：哪些接口哪些角色可以访问
5. **个人中心**：修改密码、重置密码、个人信息
6. **用户管理（管理员）**：新增 / 禁用 / 删除用户、分配角色
7. **会话管理：查看在线用户、强制踢人下线**

## 三、存储层能力

1. 关系数据库 MySQL

   - 用户、角色、菜单、业务数据、对话历史、操作记录

2. Redis

   （几乎必用）

   - 缓存、Token 存储、登录状态、限流计数、验证码、热点数据缓存

3. 文件存储

   - 用户上传文件、文档上传（RAG 知识库上传 PDF/Word）
   - 本地存储 / MinIO / 对象存储 OSS

4. **向量数据库（如果你做 RAG）** Milvus / Chroma / PGVector，存储 Embedding 向量

## 四、业务逻辑层（以你的 LLM 对话网站举例）

**Controller：接收前端请求，做参数接收、调用 Service、组装返回结果，不写复杂业务。**

 **Service：专门写业务规则、流程、业务计算，是整个系统的核心 接口。** 

**Serviceimpl 实现功能**

 **Mapper：只负责和数据库打交道，只做增删改查，不写业务。**

1. **业务流程编排（最核心）**

   ```
   1. 根据用户名查询用户（调用 mapper）
   2. 判断用户是否存在、账号是否被禁用
   3. BCrypt 校验密码
   4. 生成 token 存入 Redis
   5. 记录登录日志
   
   > 
   > 这一串判断、先后顺序，全部写在 Service，Controller 只调用一行 `userService.login()`。
   
   以你的**LLM 对话 RAG 系统**举例，对话的 Service 内部要完成：
   
   1. 校验该用户是否有权限使用大模型
   2. 查询数据库，读取该会话历史消息
   3. 做上下文裁剪，防止 token 超长
   4. 调用 FlagEmbedding 向量化用户提问
   5. 调用向量库检索知识库片段
   6. 把检索结果 + 用户历史 + Prompt 模板组装完整提示词
   7. 调用外部 LLM 接口（SSE 流式调用）
   8. 保存提问和回答记录到数据库
   9. 统计 token 消耗计数
   
   👉 一整套业务流程全部放在 Service。
   ```

2. **业务规则、各种判断校验**  

   > 注意：简单参数校验放在 Controller 用 @Valid；**业务规则校验写 Service**

   例子：

   - 用户修改密码：校验旧密码是否正确，新密码不能和旧密码一样
   - LLM 对话：判断用户今日调用次数是否已经超限
   - 知识库：文档数量是否超出该用户最大限额，不允许上传 0 字节文件
   - 删除会话：判断这个会话是不是属于当前登录用户，不能越权删除别人会话

3.  **事务控制 `@Transactional`** 

   多个数据库操作需要**要么全部成功，要么全部回滚**，注解加在 Service 方法上。 例：新建对话会话，同时插入会话主表 + 插入第一条消息记录；一旦失败全部回滚。

4. **调用外部资源**

- 调用第三方 LLM API
- 调用向量数据库 (Milvus)
- 调用 MinIO/OSS 文件存储
- 调用 Redis 操作缓存
- 调用其他微服务接口

> Controller 原则上不直接访问 Redis、不直接调第三方 API，交给 Service 处理。

5. **数据组装、转换、业务计算** 

   - 从 Mapper 拿到数据库 PO 对象，做业务处理，组装成 VO/DTO 返回给 Controller
   - 统计计算：统计用户 token 消耗、统计对话数量
   - 数据处理：文档文本切割、Prompt 拼接、上下文窗口裁剪

6. **调用其他 Service**

   业务之间互相调用，例如：对话业务需要记录审计日志，就调用 `operateLogService.saveLog()`。

7. **处理业务异常**

   抛出业务自定义异常（如：`UserDisableException`、`ApiQuotaExceedException`），由全局异常处理器捕获返回前端错误信息。

8. **异步任务、定时任务业务**

## 五、安全模块（生产环境必须）

1. **密码加密存储 BCrypt，禁止明文存密码**
2. 防攻击
   - XSS 过滤输入
   - SQL 注入（MyBatis‑Plus 已经防护，但注意手写 SQL）
   - CSRF 防护
3. **Prompt 注入防护（LLM 系统重点）**，对用户输入做检测过滤
4. **验证码**：图形验证码、防止暴力破解登录
5. **敏感数据脱敏**：手机号、密码不返回明文

## 十、企业级项目实现的能力

**（1）全局异常处理**

- 异常分层：参数校验异常、业务异常、权限异常、第三方调用异常、系统未知异常
- 统一错误码：按模块定义错误码（如 10xxx 用户模块、20xxx 订单模块），附带错误信息与解决方案提示
- 实现方式：`@RestControllerAdvice` + 自定义业务异常类 `BusinessException`
- 异常日志：完整打印异常栈 + 请求链路 ID，方便排查

**（2）ELK 日志处理体系**

- **采集端**：项目集成 Logback，按级别 / 模块拆分日志文件，MDC 注入全局链路 ID（traceId），贯穿单次请求全流程
- **传输存储**：Filebeat 采集日志文件 → 输出到 Elasticsearch，按天创建索引
- **可视化**：Kibana 搭建日志大盘，支持按链路 ID、用户 ID、接口路径、错误级别检索，配置错误日志告警
- 日志规范
  - 入口出口必打日志（请求参数、响应结果、耗时）
  - 错误日志必打上下文（用户、入参、异常栈）
  - 敏感字段自动脱敏（手机号、密码、身份证）

**（3）API 接口文档（Knife4j）**

- 接口分组：系统接口、业务接口、公开接口分组展示
- 在线调试：支持携带 Token 直接调试，替代 Postman 基础功能
- 实体注释：所有 DTO/VO 字段加注释，自动生成文档说明
- 离线导出：支持导出 Markdown/HTML 格式接口文档

**（4）其他企业级能力**

- **接口幂等性**：基于 Redis + 令牌机制，防止重复提交
- **接口限流防刷**：自定义注解 + Redis 计数器，限制单用户单位时间调用次数
- **数据权限**：基于部门 / 角色的数据行级隔离，自定义注解 + SQL 拦截器实现
- **多环境配置**：dev/test/prod 三套配置，分别对应开发、测试、生产
- **代码生成器**：MyBatis-Plus 代码生成器，一键生成 Entity、Mapper、Service、Controller、基础 CRUD

## 十一 、响应链条

```
前端请求
  → Nginx 反向代理 + 跨域处理
  → 过滤器链：字符编码 → CORS → 请求体重复读
  → 拦截器：JWT 鉴权 → Redis 校验 Token 有效性 → 获取当前用户
  → AOP 切面：操作日志记录 → 接口限流校验 → 幂等令牌校验
  → Controller 层：参数校验（@Valid） → 接收请求 → 调用 Service
  → Service 层：业务逻辑处理 → 事务控制 → 读写 Redis 缓存 → MySQL
  → Mapper 层：MyBatis-Plus 操作 MySQL → 数据返回
  → 结果封装：统一 Result<T> 包装 → 异常统一捕获转换
  → 响应返回前端
```
